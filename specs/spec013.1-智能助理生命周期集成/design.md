# 设计文档 - 智能助理生命周期集成

状态：Completed（源码集成与自动验证完成）

## 1. 概述

沿用既有全局助理 Feature 和语音协调器，在 Host 增加连续对话和生命周期接口，在 Client 将入口统一到工作台。形象与语音编辑器仍复用 spec013/spec014 的实现，不创建普通 DSH 项目会话。

## 2. 数据与状态

### 2.1 档案与模型

标准性格由共享 DEFAULT_ASSISTANT_PERSONALITY 提供。初始化草稿、首次试聊与缺省创建通过同一读取函数补默认值，条件为尚未创建且性格字段缺省；显式空白、已有自定义设定和已创建档案保持原样。读取不写设置，正式保存仍采用用户编辑后的文本。基本形象名称为鱼仔（男生）、鱼妞（女生），旧内置名称仅用于写入兼容，读取归一化为新名称。

assistant 增加可选 profile（名称、性格背景、初始化标记、创建时间）和 model（提供商及模型；缺省跟随 DSH 默认）。只有显式 profile.initialized=true 表示已创建。缺少档案或明确未初始化时，旧模型和形象用于身份预填，项目范围、识别模型及音色资料保留到创建后的能力配置；资源安装和能力就绪不能提前创建助理。Host 每次读取当前设置，不缓存或推导启动时的创建状态；统一创建校验并保存成功后才放行正式文字和语音对话。

profile 增加可选 personality，保存最多 4000 字符的性格背景，旧档案缺省视为空；正式配置、预览与设置写入共用验证。正式文字与语音共用角色设定，草稿预览可独立覆盖。角色设定作为身份与交流指令加入系统提示词，不能作为项目事实或覆盖事实与权限约束。

首次创建的形象清单只读 appearance.models，不补入未登记的旧大肥鱼预设；草稿在旧选择尚未登记时使用默认女生，读取不修改原值。基础男女角色使用内置生图工具生成的透明 PNG，按固定同源 URL 加载，无手绘 SVG 角色或外部引擎。女生沿用 codingns-default 的身份与存储字段，男生为 codingns-basic-male；归一化补齐两者，容量增加为 21，保留旧 19 个自定义名额，两者不可覆盖或删除。Host 创建校验使用同一清单边界，已创建助理继续保留旧选择兼容。非内置形象在创建和管理选项中标记「外部依赖」，Live2D 单独提示引擎要求。l2d@2.1.1 仅声明为可选对等依赖，不加入生产依赖或打包清单；源码开发把它列为开发依赖，正式 Host 在用户选择 Live2D 形象并确认当前版引擎许可后，由 Host 从固定 registry 地址下载精确版本、校验 SHA-512 摘要并安装到 CodingNS 自有目录（`DSH_HOME/codingns4dsh/avatar-engine`）。Client 用本地接口声明必要事件，按选择读取 Host 已就绪的独立 ESM（标准 JavaScript 模块）运行时，优先自有目录、其次依赖解析，不捆绑 SDK，不在创建、目录读取或素材安装时提前安装第三方代码。

### 2.2 连续对话

Host 保存 schemaVersion、revision、summary、messages、contextFrom（当前范围的历史起点）。消息有稳定 ID、角色、文字、来源、时间和可选的 DSH 附件引用。Agent 重建时从最近 9 个完整问答对恢复历史；正常轮次复用原生 Agent，由宿主自动压缩上下文，不再每 9 轮强制重建。正式记录与试聊隔离。存储落在当前 DSH_HOME 下的 codingns4dsh/assistant-conversation.json，支持 CODINGNS4DSH_STATE_DIR 覆盖，原子替换；测试通过注入内存或临时目录存储隔离真实环境。活动问题和流式回复通过快照显示，只有完成的问答进入持久记录。

### 2.3 正确性属性

一个助理只有一份对话；同一请求只能提交一次。取消、清理、范围变更、重置和模块释放后，旧回调不得修改新记录。索引代次更新不清空对话；范围变更清除可发送上下文而保留显示记录。摘要不替代实时项目事实。

## 3. Host 组件和接口

### 3.1 连续对话服务

复用 AssistantTextChat 的模型目录、流式读取、超时和取消，维护文字与语音共用记录。语音包装层保留租约、epoch 和 sequence 校验；租约结束只取消本轮，不删除正式消息。

日常上下文压缩沿用 DSH Agent 的压力阈值与溢出处理，不改变部署默认配置。原手动压缩接口保留兼容：保留最近 3 个完整问答，旧材料按完整问答分批交给 LLM（大语言模型）生成不超过 4000 字符的摘要；所有批次成功后再次核对 revision 才替换记录。持久记录取消 200 条消息硬上限，仍保留 4,000,000 字符的存储保护，接近上限提示使用 `/clear`。自动上下文压缩不删除可见历史。存储失败明确报错，不能宣称刷新可恢复。普通读取和清理拒绝覆盖损坏文件，完整重置允许显式恢复为空记录。

附件由浏览器文件选择器或粘贴加入草稿，发送时编码为 name／mediaType／data；Host 在写入前检查数量、大小、编码与名称，拒绝浏览器直接提供已有引用或文件路径。图片通过原生 admitPromptContent 校验，普通文件通过 admitEncodedFile 接收，只有原生生成的 sha256 引用进入正式消息、原生 followup 内容与持久记录。文件阅读工具仅接受本助理已收到的附件标识，按只读流读取最多 128 KiB 的 UTF-8 文本；不开放任意本地文件读取，二进制文档暂不解析，图片能力取决于模型。上传指纹参与请求去重；取消先到、范围变化、清理和重置均阻止迟到上传启动模型或回写记录。调试文本接口不能绕过上传流程注入附件引用。

### 3.2 生命周期 RPC

- lifecycle/read：无输入，返回档案、连续对话与当前生成/压缩状态。
- lifecycle/configure：名称、模型、性格背景、形象 ID；工作区 ID、声音 ID 和输出后端为创建后可选能力字段。缺省时保留旧范围与音色资料，新建输出使用浏览器 TTS；显式选择 MOSS 时仍校验可用性。模型、角色设定、登记资源和范围通过校验后持久保存，创建时设置初始化标记。
- conversation/start：requestId、text 与可选编码附件；Host 接收附件、构造权威上下文，返回现有 ChatRun。
- conversation/read / cancel：requestId，读取或取消当前轮次；preview=true 指定预览。取消标记覆盖尚未完成模型目录读取的请求。
- conversation/preview：保留兼容既有草稿预览调用，独立于正式历史；现工作台不再调用此接口。
- conversation/clear / compress：清理或压缩，返回最新生命周期快照。
- lifecycle/reset：先撤销任务、停止租约和初始化，保存默认配置、清空对话和索引。

所有接口沿用 assistant namespace 和 RPC 白名单。正式对话使用受限根 Agent，只开放原管理工具、已上传附件的文本阅读工具与原生 web_search；不执行命令或修改代码。索引不可用时系统消息明确禁止凭历史编造当前项目事实，可在授权范围内查询管理工具。配置保存保持现有字段，新增字段严格校验。

Host 已注册全局搜索工具时直接继承；Web 产品关闭全局工具、改由各 Agent 预设组合时，独立助理在自身作用域注册 web_search 的薄适配入口，调用 DSH WebRuntime.search。提供商、端点、凭据、取消、来源和错误仍由原生服务管理，不启用其他 Agent 的预设或全局工具。工具继承、局部注册、模型声明及执行守卫共用白名单，web_fetch 与其他全局工具被屏蔽。服务缺失不阻塞管理问答，注册成功也不等于上游可用。诊断记录注册方式、搜索开放状态及真实搜索执行状态，不记录查询正文。清除默认编程提示后，Host 注入本助理的原生运行身份、独立目录、会话标识、模型参数、本轮时间和工具清单。

文字与语音共用陪伴和工作场景提示词，模型按当前意图及连续历史自然调整语气，不新增关键词匹配或手动模式。陪伴先回应情绪，不强行给建议；工作按最新事实查询，只有明确跟进请求才能发消息。实时公开问题先搜索，缺地点先问，不发送私有项目、附件、路径或凭据。保持默认一到两个短句、100 字以内；自定义性格及提示词保留，两版完整旧默认对话提示词读取时升级。预览与索引总结不开放联网或管理工具。

项目选择兼容原生侧栏的虚拟工作区 ID。Host 校验本地 Registry（工作区注册表）和 PeerHost 已显式加入的工作区目录；索引与增量事件按 Host/原生工作区归属匹配，同时保留用户选择的 ID。PeerHost 读取正文时恢复原生工作区 ID，目录查询不触发远端登录或正文读取。

### 3.3 初始化和重置协调

配置保存后按所选范围进行首次索引。模型或提示词变化只使对应上下文/索引失效。完整重置暂停自动索引，递增生命周期代次，撤销模型下载、TTS 初始化及旧回调；保留下载文件和素材包，仅解除配置登记。清理只清对话，不能触碰原始项目会话。

## 4. Client 工作台

### 4.1 界面结构

首次为四项身份配置与形象展示双栏，窄屏上下排列。左侧仅名称、模型、性格背景和形象，底部一个“创建并开始对话”主按钮。右侧仅显示形象、名称与背景摘要，不显示预览标题/说明、问候试听和试聊。使用宿主明暗主题、较大圆角与清晰留白；形象展示隐藏缓存诊断但保留加载及错误状态。创建后为单栏消息、形象、输入。

创建后的设置改为四个标签页：基本信息仅名称、模型、性格背景；形象管理复用原角色编辑器；声音管理提供识别模型入口、声音向导、设备及原音色管理；更多设置提供关联项目、提示词、索引调试和重置助理。日常对话没有维护工具栏，通过斜杠指令清理交流；切换标签取消尚未执行的维护确认。默认进入基本信息，前三页保留共同形象展示，更多设置使用全宽布局；通用保存和取消位于页面之外。标签支持点击、方向键、Home/End、选中高亮及窄屏横向滚动。未安装 MOSS 时使用浏览器声音，不删除音色资料。设置切换视图，不打开第二个助理窗口。

日常窗口由不收缩的标题区、可滚动的正文与不收缩的底部输入区组成，高度不超过动态视口。圆角输入栏将添加附件、电话通话和发送／停止合并在同一行；中文输入法确认和 Shift+Enter 保留原行为，正文更新只滚动消息区域。textarea 先归零高度再按 scrollHeight 自动增长，删除内容可缩回单行，最高 min(120px, 20dvh)，超过后内部滚动；宽度、窗口或软键盘视口变化时重新测量。局部样式移除输入框的拖拽、内部边框、焦点描边与阴影，按钮保留键盘焦点提示。标题配置与关闭、添加、发送、停止直接复用 DSH 图标；返回对话使用三点气泡，宿主缺少普通对话图标时沿用原生新对话气泡的轮廓与 Regular 线宽。电话在宿主缺少图标时以相同 16px 画布和 Regular 线宽补齐。语音不可用时仅禁用电话按钮并提示前往声音管理，不展示原独立按钮行及 Sherpa 技术说明段落。

输入 `/` 时提供 `/clear` 提示，点击只填入草稿；实际发送完整指令后才进入一次清理确认。日常标题栏的配置按钮左侧增加 DSH 原生重置箭头清理图标，点击仅进入同一确认阶段；初始化和配置页不展示，未读取或操作中禁用。标题与斜杠共用 requestClear，只有模态确认才调用现有 conversation/clear；停止当前生成和语音后清理消息与摘要，保留配置和索引。共享指令表包含 `/clear`、`/清理`、`/reset`、`/重置`，按 trim 后完整匹配，不把路径或带参数消息误当清理；附带文件时先提示移除，避免丢失附件草稿。确认成功后才清空文字与附件草稿；取消、上传或清理失败保留输入。

助理名称右侧的状态标签由现有文字生成、语音状态、操作锁定与项目索引状态派生，优先级为思考中、工作中、认知更新、空闲，不增加新的持久设置或状态查询。没有关联项目时不显示认知更新，停止后的旧语音状态不影响标签。

维护确认使用原生 dialog 模态框及 clear／reset-first／reset-final 三个阶段。重置第一次确认只推进阶段，不执行任何重置请求；第二次确认才复用生命周期重置操作。阶段作为组件 key，使两步确认分别挂载并将默认焦点放在取消按钮。Escape 只取消当前模态框，工作台关闭监听在确认期间停用；关闭后恢复触发元素焦点。执行期间禁用确认和取消，使用原 pendingOperation 防止重复写入；失败保留当前确认阶段并显示错误。重置仅在更多设置且设置可写时开放。

形象管理去掉 GitHub 兼容目录按钮；悬浮尺寸提供迷你 72、标准 144、自定义，只保存既有 floatingSize 值并保持旧尺寸兼容。统一「添加形象」入口选择包安装或直接素材，表单状态与原安装逻辑保持。第三方启用复选框只请求弹出原生模态协议，明确同意并保存后才挂载目录；取消不写设置，关闭协议恢复焦点，Escape 不关闭整个工作台。角色许可与完整下载仍单独确认。

第三方开关单独放在当前形象选择框下方，文字在左、复选框在右，与对话显示开关共用样式；移除说明区块的边框、内边距和默认提示。选项排版集中在 assistant-settings-styles.ts，统一 13px、常规字重和 1.5 行高，分别提供字段、复选框和开关布局供各页及模型/提示词编辑器复用。

初始化与配置采用相同紧凑布局：正文上下 11px、左右 22px，标题与底部操作区各 22px；主要字段及分组纵向间距为 11px，双栏间距为 22px。标题字号为 17px，标签与身份输入最低高度为 36px，性格背景默认四行，形象展示为 144px。保存／取消和创建按钮独立于正文滚动区并保持不收缩；保存成功后回到对话，不再产生「配置已保存」通知，错误继续显示。

### 4.2 状态归属

工作台持有当前标签和已访问标签集合，AssistantConfigurationSession 为全部配置页提供内存设置存储及资源调用代理，身份、模型、项目、形象、声音、设备和提示词共用草稿。后台正式快照刷新只更新未编辑字段，已编辑操作按最后编辑顺序重放。保存时读取最新草稿，显式提交固定模型或默认 null，lifecycle/configure 合并可选 configurationPatch 后统一验证保存；取消、返回对话和关闭丢弃。未访问页仅保留空内容区以维持标签关联，编辑器在访问时挂载；已访问页用 hidden 和 display:none 隐藏，保持实例与字段草稿，避免切页取消安装。共享形象展示不按标签重新挂载，更多设置只隐藏展示。声音编辑器接收 active 标记，隐藏时只停止试听和原录音，不重置表单或中断下载。保存、切回对话或重置时清理访问记录。

形象显示开关紧邻各自大小字段上方。配置页确认裁剪只发布草稿头像，底部保存后才持久化并通知正式头像服务。设备与删除资源也延后提交。主动下载和声音导入经 configuration/capabilities 能力查询确认 Host 支持 prepareOnly，再准备及验证文件，返回待保存资源记录，不改当前识别环境或声音后端；首次第三方协议需统一保存后才能读取目录。Host 与浏览器本地保存分开执行，不宣称跨存储事务；本地步骤失败保留草稿并提示重试。独立设置入口与原资源接口保持兼容。

正式消息以 Host 生命周期快照为准；Client 只保留文字／附件草稿、配置草稿与麦克风局部状态，工作台试聊、轮询和问候试听状态已经删除。附件选择时不上传，成功开始问答后清空草稿，上传失败不丢失文件。消息中仅展示已发送附件名称，原生引用可随共享历史用于文字和语音追问。不把 index.generation 当作清空历史的依据。全局按钮、悬浮形象与设置页复用同一入口。打开不会启动麦克风；离开语音和关闭面板停止捕获/播报，保留已完成消息。

悬浮形象仅在档案明确已创建、悬浮开关打开且工作台关闭时挂载，根容器可见性使用相同判断。通过已有共享设置订阅更新创建和重置状态，不改写展示开关；缺少档案或未初始化时隐藏悬浮层，配置与预览中的形象仍可使用。此判断只关联助理创建状态，不要求语音模型初始化。

创建表单只发送四项身份字段，不查询项目目录、索引诊断或 MOSS 目录，不发起试聊或问候试听。创建后再订阅项目目录与查询音色可用性；原接口传完整能力字段的调用继续兼容，显式选择 MOSS 的失败如实返回。

### 4.3 实时通话展示与归档

识别默认值集中在 DEFAULT_VOICE_MODEL_ID，使用中英双语实时模型；模型目录顺序、声音向导和原初始化窗口复用此值，旧 DEFAULT_LIGHT_VOICE_MODEL_ID 导出保留为兼容别名。已有模型与路径保持不变。

Client 开始通话时给 voice/start 传独立 voiceSessionId，Host 在有效租约后创建 AssistantVoiceSession（id、startedAt、endedAt、messages），时间由 Host 记录。连续对话消息附可选 voiceSessionId，通话保存自己的文字副本，避免模型压缩删除详情；仍在同一原子对话文件中保存，保留旧 schemaVersion 及 4 MB 上限。开始新轮次按 UTF-8 字节数检查容量并预留文字和工具摘要空间。挂断先结算完整回复及残句，再停止租约；自动失效同样归档。旧客户端未传 ID 时沿用原消息语义。Host 恢复时结算没有租约的遗留记录，时间以最后发言估算，不继续显示通话中。

AssistantAgentAdapter 观察本助理会话的 tools/execute（执行前）及 tools/result（真实最终结果），不替换工具实现与权限校验。AssistantTextChat 按调用 ID 更新最多 24 个有界记录；参数最多 4000 字符、结果最多 6000 字符，常见凭据字段及字符串脱敏。通话保留 workspace／web-search／attachment 分类、状态、时间和摘要；打断时运行中记录转为 cancelled，半轮文字只保存在通话记录，不伪造完整问答加入模型历史。

工作台通话中用 AssistantRealtimeCall 替代普通聊天与输入栏，沿用 AssistantAvatarSlot 展示当前形象，三项控制复用当前适配器。麦克风同时关闭轨道、上传零 PCM、过滤识别事件；MOSS 以 GainNode（音量节点）静音，浏览器声音静音时取消当前播报并跳过后续段。输出设备切换只在 AudioContext.setSinkId 可用时开放。底部文字显示识别及 LLM 增量，长文本自动滚到最新一行；文字不承诺与正在播放的音频逐字对齐。

挂断后用 assistantConversationTimeline 将已结束通话对应气泡替换为一张卡片，普通文字和旧语音消息保持原样。卡片用非空角色发言计数，详情使用原生 dialog 模态框显示全文、打断标记及工具摘要；Escape 只关闭详情。明暗主题沿用 DSH 主题变量，小屏限制形象高度并保持三个按钮可见。

GlobalVoiceOverlay 单独保存 callMinimized 和本次通话计时起点。收起只隐藏 AssistantWorkbench，保留 ClientSherpaVoiceAdapter、设备状态和历史订阅；隐藏窗口不监听 Escape，通话页暂停计时刷新并卸载动画形象。恢复只切换显示，不调用 start／stop。已开启悬浮形象时复用 FloatingAssistantAvatar，否则用 FloatingVoiceCall；二者共用拖动容器、计时角标与字幕气泡。发声指示取实际 speaking 状态且排除关闭扬声器，字幕替换累计快照并支持滚动回看。气泡位置随拖动和视口变化约束在屏幕内；极矮横屏允许局部覆盖形象。disabled 或停止操作清除收起状态，启动失败和致命错误恢复窗口，stop 事件保留错误原因。计时起点由 Client 请求通话时固定，Host 归档仍使用实际租约开始和结束时间。

聊天消息与通话详情共用 AssistantConversationMessageView，统一 14px 字号、1.65 行高、换行、角色标题和静态头像。通话详情显式指定用户右侧、助理左侧，消息最大宽度 88%；当前形象和 Client 服务从聊天卡片传入模态框，AssistantAvatarPortrait 复用已有头像缓存和用户裁剪，不为每条消息创建动画实例。普通聊天保持原有排列，附件、流式回复及空状态继续沿用原逻辑。

AssistantTextChat 在实际工具事件到达时立即发布累计快照，首次调用记录累计正文的 UTF-16 长度 textOffset，按调用 ID 更新且位置不变；完成时校正原生适配器 trim 移除的开头空白。assistantMessageTimeline 按位置拆分正文、穿插工具，同位置并行调用保持开始顺序，状态变化不移动节点。AssistantMessageContentView 供普通消息、流式消息、实时字幕及通话详情共用，工具卡片仍由 AssistantToolCallsView 展示，参数／结果默认折叠；删除通话详情底部汇总，各轮只显示自己的工具。字段可选并随记录持久保存，旧记录工具位于所属回复前；损坏位置在恢复时拒绝，截断残句的位置按现有正文长度限制。工作台沿用活跃约 600 毫秒的生命周期 RPC 刷新，不随语音正文增量重复下发工具明细。流式与最终消息沿用同一消息 ID，状态变化触发跟随滚动，同内容刷新不触发。展示时间线不修改原始 text，逐句 TTS 仅使用 text，不因工具变化播报或重读。

工具卡片使用原生 details／summary，将类别图标、名称、状态和短时间收拢到 8px × 10px 内边距的标题栏；状态文字与颜色同时区分运行、成功、失败和取消，完整时间通过 time 语义及提示保留。长名称收起时省略、展开后换行；参数与结果分块展示，单块最高 160px，允许键盘聚焦和滚动。通话卡片采用 32px 图标、两行摘要、独立时长标签及 10px × 12px 内边距；详情模态框内边距 16px，元信息自适应分列，消息间距 8px，正文仍保持 14px／1.65。AssistantRecordStyle 共用悬停、按下、焦点与展开箭头样式，沿用宿主明暗主题变量；展示层不修改数据结构、工具顺序或语音输入。

## 5. 错误处理

模型目录为空、设置拒绝、素材缺失、语音不可用、索引不完整分别显示实际错误。保存失败不跳转；压缩失败保留原数据；重置失败可重试，不能继续旧生成。后台操作每次落盘及配置写入前核对撤销信号，避免重置后自动恢复旧设置。

## 6. 验证策略

用注入的 LLM、内存/临时仓库存储验证创建、跨模式追问、刷新回读、索引更新、范围隔离、压缩失败、清理及迟到回调。对正式 Client 视图做 React 渲染与交互回归，验证单栏、初始化预览、共享编辑器入口和空状态。运行原有索引/语音/形象/权限定向回归、pnpm typecheck 与文案检查；不执行含构建的 pnpm test。
