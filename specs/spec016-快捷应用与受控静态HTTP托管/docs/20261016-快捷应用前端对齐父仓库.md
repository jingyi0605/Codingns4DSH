## Resulting behavior

- The native footer displays the app grid directly above Settings on mount, with no preliminary click or list dialog. A compact heading/count and add/edit/done icon controls follow the parent footer rail.
- Wide mode uses four columns; the collapsed 56px sidebar uses one column of icons with accessible labels and source tooltips. The grid has bounded scrolling so Settings remains reachable.
- The launcher presents apps as name-based tiles. Edit mode makes unavailable apps editable without attempting to launch them. Tooltips retain the owning Host, workspace, entry and unavailable reason; accessible names include the app title and unavailable reason.
- Editors group basic source fields first and put ordering, application folder, SPA navigation and resource mounts under Advanced options.
- Permission/revocation/removal controls live in the editor. Unsaved source changes must be saved before using those controls; cancelling removal returns to editing, and removal explicitly leaves source files intact.
- Form errors retain draft content. Successful saves and grants use status messages rather than error alerts. Loading, empty and failed-load states are distinct.
- Only shortcut editors, permission/removal controls and HTML/text viewers use dialogs. Back and Close return to the existing inline grid and retain launch cleanup; generation checks prevent stale connection responses from replacing the current list or restoring closed screens.
- New visible text is registered in both English and Chinese dictionaries. Theme colors and text sizes follow DSH's existing settings.
