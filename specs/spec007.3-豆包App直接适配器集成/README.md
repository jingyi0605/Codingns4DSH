直接连接已安装、已登录的豆包 App，参考前期实测的协议逻辑，不安装或调用 doubao-cli。首版使用原生隐藏后台页和 HTTP/SSE（服务器发送事件）传输，提供快速对话、专家思考、云端工作任务、原会话续聊和普通回答停止。
