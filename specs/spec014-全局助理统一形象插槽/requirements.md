# 需求文档 - 全局助理统一形象插槽

状态：In Review（源码完成，待浏览器与真实模型验收）

## 简介

全局智能助理目前只有按钮和对话窗口。用户希望增加宠物式悬浮入口，并在对话中看到同一角色的全身形象，能够自行更换素材。现成插件可提供渲染参考，但不能接管 CodingNS 的全局语音和受管工作区逻辑。

## 术语表

| 术语 | 含义 |
| --- | --- |
| 形象插槽 | 容器向渲染器传入同一角色、状态和尺寸的接口 |
| 精灵图（spritesheet） | 将逐帧动作排成固定行列的图片；支持 Codex v1/v2 布局 |
| Live2D | 通过模型、贴图和动作文件驱动的二维角色 |
| 双展示 | 页面悬浮宠物和全局助理对话窗口两个位置 |

## 需求

### 需求 1：统一配置和可扩展接口

**用户故事：** 作为用户，我希望只选择一次角色，悬浮宠物和对话窗口就能显示同一个形象。

1. WHEN 用户选择形象 THEN System SHALL 为两个展示位置使用同一份持久配置。
2. WHEN 扩展注册新渲染器 THEN System SHALL 通过公开注册接口使用它，无需修改两个容器。
3. WHEN 旧设置缺少形象配置 THEN System SHALL 保留原有助理入口，提供内置形象且默认关闭悬浮显示。
4. WHEN 用户导入形象包 THEN System SHALL 由格式适配器转换为统一契约，保留作者、许可和来源；支持 CodingNS 清单、Codex pet.json、DSH Live2D pet.json 和 Cubism 模型清单。
5. WHEN 用户管理形象列表 THEN System SHALL 通过统一管理接口完成新增、更新、删除、选择和展示设置写入，沿用设置权限与版本检查。
6. WHEN 同一形象包提供不同展示素材 THEN System SHALL 根据 floating/dialog 选择对应素材，状态图片与 Live2D 动作映射均来自形象包；旧地址配置继续可用。
7. WHEN 扩展适配器注册或注销 THEN System SHALL 即时更新导入选项，且注销不删除已经导入的形象或影响另一 Client 实例。
8. WHEN 用户打开新配置的形象列表 THEN System SHALL 提供生图生成的男女基本形象和用户已登记形象，默认女生；已有选中预设继续兼容，不主动添加其他第三方形象。基本形象通过固定同源图片 URL 展示，保持旧默认 ID 与自定义容量；第三方通过仓库或资源 URL 手工安装成功后才登记并启用，作者与许可跟随安装记录。

### 需求 2：悬浮宠物

**用户故事：** 作为用户，我希望拖动页面宠物，并点击它打开全局助理。

1. WHEN 用户开启悬浮显示 THEN System SHALL 显示可拖动、可通过键盘打开助理的形象。
2. WHEN 用户拖动、调整窗口尺寸或刷新页面 THEN System SHALL 保持可见位置，不误触发打开对话。
3. WHEN 对话窗口打开 THEN System SHALL 暂停或卸载悬浮渲染，避免同时渲染两个 Live2D 上下文。

### 需求 3：对话中的全身形象

**用户故事：** 作为用户，我希望对话时看到角色，同时继续使用现有识别文本、开始/停止和调试功能。

1. WHEN 用户启用对话形象 THEN System SHALL 在原对话窗口内完整容纳角色，使用自适应布局。
2. WHEN 形象不可用或关闭 THEN System SHALL 保留完整文字和语音控制。
3. WHEN 用户打开形象或对话 THEN System SHALL 不自动启动麦克风或创建普通 DSH 会话。
4. WHEN 用户在助理对话窗口更换形象 THEN System SHALL 提供直接可见的「助理形象」入口，复用统一配置，关闭对话形象后入口仍可使用。

### 需求 4：自定义素材与状态

**用户故事：** 作为用户，我希望更换图片、Codex 精灵图或 Live2D 模型，让角色反映全局助理状态。

1. WHEN 用户添加有效图片、精灵图或 Live2D 地址 THEN System SHALL 将其加入角色清单并可即时选择。
2. WHEN 语音处于监听、播放、准备或错误状态 THEN System SHALL 映射到角色状态，不通过普通当前会话推断。
3. WHEN 精灵图采用 v1/v2 布局 THEN System SHALL 按正确行列显示动作，不将整张图集作为角色显示。
4. WHEN 渲染失败、切换角色或模块停用 THEN System SHALL 显示可用的内置回退并释放旧资源。

### 需求 5：兼容、性能与素材边界

**用户故事：** 作为维护者，我希望形象不增加语音和派发复杂度，不让普通入口承担 Live2D 下载成本。

1. WHEN 用户只使用内置/图片/精灵图形象 THEN System SHALL 不加载 Live2D 引擎。
2. WHEN 页面隐藏或用户减少动态效果 THEN System SHALL 暂停精灵图动画；Live2D 隐藏时释放实例。
3. WHEN 加载 Live2D THEN System SHALL 使用固定同源运行时入口，不允许用户提供任意脚本地址。
4. WHEN 分发插件 THEN System SHALL 保留复用代码的 MIT 署名，不随包复制非商业角色模型。
5. WHEN 本轮验证 THEN System SHALL 只使用不产出构建文件的类型检查和定向测试，不操作 Desktop 或启动服务器。
6. WHEN 用户安装形象 THEN System SHALL 下载完整素材并重写模型文件引用，持久存放在独立数据目录；刷新与 Host 重建直接读取本地资源，默认不登记旧角色专用路由。既有旧预设的精简缓存仅用于兼容历史配置。
7. WHEN 素材尚未就绪 THEN System SHALL 在统一插槽显示动态载入占位和真实进度条，支持减少动态效果；正式 npm 包在普通运行环境不显示缓存、下载次数、耗时、完成摘要或调试 tooltip，也不发送缓存诊断请求。仅由专用 dsh-stage0 启动器开启这些诊断；缺少环境标识时默认关闭，不改变加载完成确认、错误回退和缓存机制。
8. WHEN 评估刷新后的本地持久化 THEN System SHALL 区分资源文件缓存、静态形象预览和运行中的 Live2D/WebGL 实例，说明各自的恢复能力；不得将持久化 loaded 标记解释为实例已经恢复。本阶段只评估实现方案，不宣称已实现跨刷新即时显示。
9. WHEN 用户刷新或再次加载支持预览的形象 THEN System SHALL 在统一插槽先显示本地有效透明预览，并保留加载动画与真实进度；后台完成真实渲染后淡入替换。预览按形象、资源地址/版本、渲染器版本、展示位置和构图隔离，有尺寸、容量与有效期限制；空帧、跨域捕获失败、数据库不可用和迟到回调不得阻断模型。删除自定义形象后清理预览，卸载时取消旧读写并释放临时图片地址；旧扩展无需修改。
10. WHEN 用户填写 GitHub 仓库/目录/文件或 HTTP(S) 素材地址 THEN System SHALL 通过来源适配器发现候选，格式适配器转换清单，素材适配器下载并本地化依赖；不执行上游安装脚本。支持运行期注册与注销，安装失败/取消不改变当前形象，设置保存拒绝清理本次未使用的新素材，卸载不删除其他角色正在使用的素材。
11. WHEN 用户浏览兼容形象 THEN System SHALL 在助理形象页面提供本仓库 GitHub 目录链接；目录包含序号、名称、仓库地址、真实素材作者、简介和备注，并提供固定版本的可安装清单及素材许可。按用户选择仅保存目录与清单，素材仍由用户手工安装后登记，不增加默认形象或 npm 素材体积。
12. WHEN 用户管理形象 THEN System SHALL 默认提供鱼妞、鱼仔及已安装记录；独立同意当前版第三方使用说明后才读取第三方目录元数据，选中未安装记录后自动下载完整素材并在右侧形象区域真实预览，无需单个形象许可确认或手动下载按钮。正式采用时必须另外确认所选形象许可，只有正式安装及设置保存成功后才登记启用。协议版本和时间持久保存，关闭列表不删除已安装素材，版本变化需重新同意。Host 对预览与采用均校验协议、角色版本和写入权限，仅正式采用校验许可确认；失败、取消或关闭列表的迟到结果不得改变当前选择。目录与安装清单元数据可随包提供，第三方美术及引擎仍不内置，旧 URL 安装接口继续兼容。
13. WHEN 用户启用第三方形象 THEN System SHALL 将目录条目合并进「当前形象」同一个下拉列表，名称旁显示独立彩色「第三方」标签，列表选项、当前选中项和创建页标记一致，不提供独立目录选择列表。已登记角色与目录条目按安装后的模型 ID 去重，保留用户命名和旧选中预设；未安装条目仅作为展示选项，不占用持久清单容量，选中后预览并等待许可及下载确认。已安装角色直接切换，关闭第三方目录仍保留已安装选项与实际选择。
14. WHEN 用户选择形象 THEN System SHALL 通过渲染适配器自动生成透明静态头像，在正式/流式助理消息和 `data-codingns-global-voice-button` 共用并同步切换。图片取待机素材上部，动作图集只取待机首帧，Live2D 优先复用已绘制透明预览；旧扩展可通过预览接口兼容，或提供可选头像生成接口。头像按资源与适配器版本隔离，独立有界持久化，刷新复用已生成图片；生成失败、跨域限制或存储不可用不阻断对话。快速切换取消旧任务并隔离迟到结果，删除角色清理对应缓存；头像变化保留原生按钮焦点和点击行为，不自动启动麦克风。
15. WHEN 用户微调头像 THEN System SHALL 将名称和 44×44 头像设置置于同一行，名称在左、头像设置在右，裁剪面板在下方整行展开；使用成熟裁剪组件支持拖动、方向键、触控和缩放，实时展示圆形预览；工作台「确认裁剪」暂存 128px 透明 PNG，底部统一保存后同步更新对话与全局按钮，取消或保存失败保留原头像。编辑按需读取完整静态帧，旧扩展兼容既有头像；手动裁剪图片和百分比构图按角色、资源及适配器版本独立保存在当前浏览器，不按自动预览缓存期限失效，刷新及再次编辑恢复上次构图。切换或删除形象、只读状态及组件卸载正确取消在途编辑并回收资源，自动帧不得覆盖用户设置。
16. WHEN 用户临时预览第三方形象 THEN System SHALL 在选择后自动下载并于右侧形象区域加载完整本地化素材，不再显示仓库宣传图或在列表下方另设预览。下载和临时模型加载只在预览位置显示动态效果，不提供停止预览按钮、下载状态文字、独立下载组件或进度条；自动下载不锁定形象列表，失败后重新选择同一条目可重试。许可勾选只控制正式采用，不影响预览。素材进入独立临时目录，预览不修改实际角色或持久清单，不写长期预览及头像缓存；切换形象、切换设置页或关闭窗口释放渲染器并自动清理临时目录。失联后由心跳超时清理，Host 模块停用清理全部租约，取消后的迟到请求和答复不得复活预览。用户正式采用时复用已下载的完整素材，保存失败回收新建正式副本，临时清理不得删除已登记素材。Live2D 引擎在用户选择 Live2D 形象并确认当前版引擎许可后，由 Host 从固定地址下载精确版本、校验摘要并安装到 CodingNS 自有目录；源码开发依赖或用户手工安装的引擎继续沿用，未确认许可前不发起下载。
17. WHEN 用户在工作台编辑形象配置 THEN System SHALL 仅修改统一配置草稿，点击底部保存后才应用选择、第三方协议、登记记录、显示、尺寸及头像；取消或关闭丢弃草稿。两个显示开关分别位于对应大小字段上方；主动下载可准备素材，但不提前启用形象。独立扩展和原设置接口继续兼容。
