# 20261007-形象渲染上游复用调查

## 两项上游结论

- [dsh-live2d-avatar](https://github.com/clown139880/dsh-live2d-avatar)：`src/client/stage/HeroineStage.tsx` 和 `src/client/pet/HeroinePet.tsx` 都实例化 `L2dAvatarEngine`，分别注册在 conversation.view 和 shell.overlay。引擎使用 l2d，负责 load/setState/resize/destroy。插件入口依赖旧 `dsh-client-runtime`，并带独立 ASR/TTS、prompt 注入和 Desktop companion，因此不整体作为依赖接入。
- [codex-to-dsh-pet](https://github.com/Signalight/codex-to-dsh-pet)：`packages/dsh-codex-pet/src/client.js` 中前段是无框架 DOM 渲染核心。单帧 192×208，8 列，v1 9 行、v2 11 行，使用 requestAnimationFrame 和 backgroundPosition；后段是会话读取、气泡、总结和上游设置页。本项目复用帧布局与渲染方式，不接入后段会话逻辑。

## 引擎与许可

2026-10-07 核对 npm `l2d@2.1.1`：提供独立 ESM 文件 `dist/index.js` 和类型定义，支持 Cubism 2/3+ 模型；没有 React 依赖。`index.min.js` 实际为全局 IIFE，没有 ESM 导出，不能用于动态 import。本项目固定使用 `index.js`，真实依赖读取测试检查 `init` 导出。它在浏览器初始化时集成 Cubism SDK，应与引擎自身 MIT 许可分别保留第三方声明。

两项 DSH 插件代码都是 MIT：上游 copyright 原文会保留在仓库第三方声明。Codex 示例角色 Nastya 是 CC BY-NC 4.0，Haru 使用 Live2D 素材许可；本实现均不复制，默认形象由仓库原创 SVG 绘制。

## 本仓库边界

全局助理与对话已有未提交改动；实现保留其按钮、语音初始化、租约、受管范围和调试入口，只新增共享形象配置与展示。Live2D 两个展示位置互斥挂载，避免两个上下文同时占用引擎状态。源码测试可以核对生命周期，不能代替真实 WebGL 与用户全身模型验收。
