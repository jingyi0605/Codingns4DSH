# Magpie 用量读取实现与验证

日期：2026-10-20

> 历史实现记录：本文记录的早期 `modelProvenance` 分流设计已被 2026-10-21 的范围调整移除。当前实现不保存 Magpie 来源，也不提供模型切换；请以 `20261021-Magpie范围调整与代码清理.md`、Spec 的 requirements/design 和当前代码为准。

## 本轮结果

- 新增 Host 侧 Magpie 用量读取器。只有当前模型 ID 精确出现在对应 Agent 的 Magpie 目录中，才会请求本机回环 Gateway。
- 用量汇总、与当前 Agent 和会话 ID 精确匹配的会话统计、单会话路由分别返回，不把汇总数据记到单个会话名下。
- 如果 Host 保存的 `providerSessionId` 与 DSH session ID 相同，按“Agent 会话未关联”处理，不把 DSH ID 发给 Magpie。客户端缓存区分 Agent session ID，并在回合状态变化后重新读取，避免新绑定继续显示旧快照。
- 弹层把网关总量和当前会话数据分开呈现，补充缓存读写 Token、输入/输出合计和更新时间；窄屏/长内容可在弹层内滚动。
- 早期版本曾由 Host 保存 `modelProvenance`，并据此分流用量请求；该状态和分流方式已移除。当前 Host 每次订阅请求都基于当前会话的适配器、模型和精确 Magpie 目录匹配直接执行只读检测，未匹配时回到普通 Provider 用量路径。
- 当前实现不接受 Client 提供的来源提示，也不把 Magpie 来源持久化到 DSH 会话；模型选择仍完全使用 Agent 自己的普通模型目录。
- 路由查询只在弹层打开时发起。请求前要求 Magpie 用量响应中存在同一个 Agent 和会话 ID；路由响应还必须回显同一 ID。弹层关闭、会话切换或 Host 请求取消时会取消在途查询。
- Magpie 用量读取失败时，Host 返回现有订阅读取结果；旧版 Host 直接返回订阅对象时，Client 仍按原用量卡片处理。
- 所有 API 结果都经过白名单字段筛选，并限制响应大小和请求时间；原始错误、凭据、提示词和回复不会进入 Client 数据。

## CLI 与 API 证据边界

- 只读执行 `magpie --version` 得到 `magpie 0.1.1295`。
- 只读执行 `magpie models claude` 和 `magpie models codex`。两者均显示模型行、对应 Agent 的说明行，以及 `http://127.0.0.1:3425/v1`。测试夹具保留行格式但替换了真实模型和 Provider 名称。
- 依据 Magpie 公开源码核对 `GET /v1/magpie/usage?period=today`、`GET /v1/magpie/route?session=<id>` 的字段形状：
  - https://github.com/yetone/magpie/blob/main/internal/gateway/usage_api.go
  - https://github.com/yetone/magpie/blob/main/internal/usageapi/usageapi.go
  - https://github.com/yetone/magpie/blob/main/internal/gateway/session_route.go
  - https://github.com/yetone/magpie/blob/main/internal/usage/usage.go
- 本轮没有启动 Magpie Gateway，也没有向本机 Gateway 发请求；API 行为由 fake fetch 覆盖。当前也没有证据证明 CodingNS 的 `providerSessionId` 在每种运行情形下都会被 Magpie 记录为同一会话 ID。
- 因此，即使代码支持安全匹配，实际路由仍可能不可用；只有找到精确的 Agent+ID 用量记录，且路由响应回显该 ID，才会展示路由。不会使用 DSH session ID 代替。

## Agent 覆盖边界

- **已验证来源识别与用量分流**：Claude Code、Codex、Command Code，以及目录映射测试覆盖的 DSH、OpenCode、Pi、Grok、Gemini、Kimi、MiniMax Code、ZCode、CodeBuddy、WorkBuddy、Cursor、Qoder、Antigravity 等适配器。
- **历史模型选择与持久切换证据**：早期实验只覆盖 Claude Code 和 Codex；相关选择器、setter、回读和 `MAGPIE_SWITCH_AGENT_BY_ADAPTER` 已从当前代码移除。
- **目录映射不等于真实 Agent 回合验证**：其他映射仅证明 Host 能按准确 Agent ID 解析目录并识别模型；没有证明它们都能通过自身 CLI 使用或持久切换 Magpie 模型。
- **真实环境未验证**：没有启动 Magpie Gateway，没有向真实 Gateway 请求 usage，没有运行真实 Agent inference，也没有操作 Desktop。
