## Cause in the session log

1. The first `request/context` for `auto/gpt-6.1-sol` contains no context capacity.
2. Later context and usage events repeatedly supply `258400`.
3. `src/host/cli-adapters/model-catalog.ts` previously mapped `gpt-6.1-sol` to the stale value `258400`.
4. `CodingNsCliAdapterRegistry` used that static value for `request/context`; the Codex driver then anchored the first usage window in `stabilizeCodexUsage` and preserved it against later conflicting values.

This is a Host-side metadata-source error, not a display-unit or K/M formatting issue. The stale window persisted into usage ratios and compaction decisions.
