# Spec 空白模板

本目录是一套可复制的新 Spec 空白模板。

建议用法：

1. 复制整个 `specs/000-Spec规范/Spec模板/` 目录
2. 重命名为新的 Spec 目录，例如 `specs/spec002-能力名称/`
3. 将以下占位符统一替换：
   - `<Spec编号>`
   - `<功能名称>`
   - `<需求名称>`
   - `<阶段名称>`
   - `<任务标题>`
   - `<设计章节编号>`
4. 按需补充 `docs/` 下的接口、联调、验收文档

新建或修改 Spec 前，先读本仓库根目录 `AGENTS.md` 的「Spec 文档规则」。那里规定了文档要写成人话、任务必须回答的七个问题、禁用黑话清单和状态回写要求。

本模板的目标：

- 快速建立标准目录结构
- 快速生成三份主文档
- 保证任务具备独立执行所需的上下文信息

## 模板内容

- `requirements.md`：需求文档模板
- `design.md`：设计文档模板
- `tasks.md`：任务文档模板
- `docs/README.md`：补充文档目录说明

## 使用要求

复制后请至少确认以下事项：

1. 每条需求都有编号、用户故事、验收标准
2. `design.md` 的章节有稳定编号，可被任务引用
3. `tasks.md` 的每个任务都能回答七个问题：做什么、做完看到什么、依赖什么、先看哪些文档、主要改哪些文件、明确不做什么、怎么验证
4. 任意打开一个任务，都能快速知道要看哪些需求、设计和补充文档
