Date: 2026-10-17. Scope: repository source, deterministic tests, and the two session exports supplied by the user. No application profile or installed Agent was changed.

## Confirmed defects and changes

1. **Native model selection inherited stale preferences.** Native Team creation selected a provider/model using the DSH catalog, but `registry.setSession()` filled its omitted effort from remembered native preferences. A previously selected reasoning model's `high` effort could therefore reach a different model. Native child initialization now disables model-selection inheritance while retaining independent display preferences. Explicit supported effort and ordinary session preferences remain available.
2. **Optional internal translation could cancel accepted Agent work.** Prompt translation raised the user-submission cancellation exception when its settings/model key changed, the selected adapter changed, or the translation service deactivated. Both settings invalidation and deactivation reproduce the exact terminal error in deterministic tests. Internal invalidation now cancels translation work and returns the complete original assembly/messages. Agent interruption, feature disposal, and actual user-message retry/send/cancel semantics retain their existing cancellation behavior. The exports do not contain the translator's invalidation reason, so they cannot establish which refresh or lifecycle event caused these particular runs to cancel.
3. **Child settlement input could be dropped or replay the old task.** The external input tracker recognized direct peer relays but ignored native `subagent-settled` notices. A later request could therefore select the original human prompt instead of the child's closing result. Native settlement notices now use the same ordered delivery tracking and uncertainty checks as peer input. Internal completion notices bypass user-input translation. Unknown notices and historical uncertain deliveries are not automatically replayed.

The full source suite passed **3,542 tests**, with **14 explicit skips** and **zero failures**. Both alpha.2/alpha.3 native TeamService fixtures passed. Typecheck, version/capability checks, localization, Spec links, and whitespace review passed. Source tests cover the actual prompt-assembly and external LLM hooks using fake provider execution. Native TeamService checks import the alpha.2 and alpha.3 libraries from the earlier dedicated temporary installations; they do not run a server or external CLI. These checks do not establish a new live OpenCode certification or a deployed fix in the user's application. Existing failed native members are not automatically recreated, historical inbox items are not automatically resent, and completed task revisions are not rewritten. A new live run remains necessary after the source changes are loaded into the intended runtime.
