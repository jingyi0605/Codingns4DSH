## 当前真实范围

Spec003 只实现三件事：

1. 读取 Workspace 级 `.codingns/debug.json`，按配置的终端、相对目录、命令和参数启动。
2. 检查配置中的端口，并在用户明确确认、Host 重新核验进程身份后结束对应监听进程。
3. 将已确认监听的指定进程服务绑定到插件内部反向代理。

已有终端 PTY 启动器是前置能力，可以复用插件自身实现；反向代理必须在插件内部实现。禁止调用 CodingNS 父仓库接口或私有源码，只能参考其行为。

## 终端规则

- `terminal.id` 只用于打开或恢复 DSH 原生 Terminal。
- `instance.id` 才是运行、恢复、查询、端口关联和停止的主键。
- Session 切换、侧栏关闭、插件卸载和 generation 切换只释放 attach/subscription，不结束运行实例。
- 只有用户明确停止时才结束终端进程。
- 禁止把命令字符串写入已有交互 Shell。
- Client 不得直连 Host、取得 Host token、提交绝对路径、PID 或任意端口。

## 开发顺序

按 `tasks.md` 推进：

1. Workspace 配置文件读写和路径校验。
2. 复用 `terminalProcess/*` 完成 PTY 启动和按 `instance.id` 停止。
3. 按配置端口检查监听状态，执行前重新核验后结束进程。
4. 将运行实例绑定到插件内部反向代理。
5. 提供最小 DSH 调试入口和三条主链路验收。

明确不做：非交互 `runtimeMode=process`、框架分析、worktree 继承、多服务编排、端口租约、日志平台、AI 补丁和新的代理引擎。

## 必须遵守

- 不修改 DSH 核心，不覆盖默认 `connection`。
- 不让浏览器直连 CodingNS Host。
- Host 重新校验 Workspace、Session、路径、配置版本和进程身份。
- 不泄露 Host token、refresh token 或秘密环境变量。
- generation 切换时旧异步结果不得回写新状态。
- 插件停用时释放订阅、监听器、定时器和 attach；除非用户明确停止，不得结束项目进程。
- 不主动启动开发服务器。
- 所有相对导入带 `.js` 后缀，文档和沟通使用中文。
- 使用 `apply_patch` 修改文件，不回滚无关工作区改动。
