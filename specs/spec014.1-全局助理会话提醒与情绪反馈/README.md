## 核心方案

复用现有受管工作区、原生会话桥和统一形象插槽，增加独立通知服务。语音动作与会话情绪分别表示，网页和原生悬浮形象消费同一通知快照；通知不会启动麦克风、调用模型生成文案或自动续跑会话。
