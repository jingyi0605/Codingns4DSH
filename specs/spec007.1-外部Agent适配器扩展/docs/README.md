## 文档规则

- 新增说明文档使用中文，文件名以 `YYYYMMDD-` 开头。
- 外部产品行为、版本差异和协议证据写进选型矩阵，并标注证据等级。
- 规则性内容（怎么做才对）写进接入规范。
- 社区项目或第三方包的结论只能作为线索，必须与官方文档区分标注。
- 未实测的事实写成待实测项，不得写成已确认结论。
