# 全局助理五步索引调试与 LLM 文本问答记录

日期：2026-10-07

## 用户目标与确认

用户提供 `assistant-debug-2026-10-07T02-34-44-065Z.json`，希望直接看到索引范围、范围内工作区和会话、当前索引结果、索引触发与记录，以及脱离语音的 LLM（大语言模型）文字对话。

通过原生问题面板确认：复用 DSH 已配置模型，先做只读索引问答，暂不派发任务。此次扩展独立文字调试，正式语音助理消息界面继续由后续联调设计。

## 快照中的实际问题

快照纳入 8 个会话，状态全部未知，四个业务分组为空，用户无法判断究竟是没有工作还是没有读取到可靠状态。部分正文摘要只剩 DSH 注入的时间上下文；v4 助理正文嵌套在 `data.message.content` 中，原读取器没有正确提取。旧面板还把排除记录、底层接口和 JSON 堆在同一视图，文字预览实际走关键词规则，无法用来测试 LLM。

## 最终操作流程

入口：助理窗口或设置页的「全局项目状态调试」。

| 步骤 | 用户看到什么 | 操作 |
| --- | --- | --- |
| 1. 设置索引范围 | 可选工作区、名称、路径、已选数量 | 勾选即保存，归档会话始终排除 |
| 2. 范围内工作区和会话 | 按工作区列出会话及状态；空工作区也可见 | 检查范围成员，展开查看标识与更新时间 |
| 3. 当前索引结果 | 索引时间与版本、正文质量统计、汇总与每个会话的正文摘要 | 点击「执行索引」读取正文 |
| 4. 索引记录 | 时间、触发来源、范围、耗时、计数、失败原因及逐会话读取结果 | 展开最近 30 次记录 |
| 5. LLM 文本对话 | DSH 模型选择、用户消息和助理逐步生成的回复 | 多轮提问、停止回复、重新开始对话 |

「刷新面板」只重新读取元数据，不执行正文索引。高级诊断折叠展示接口接入、排除原因和原始 JSON，仍可下载快照。按钮在窄屏换行，内容纵向滚动。

## 索引数据与记录

- 索引保存受管且未归档会话的标题、所属工作区、状态、等待类型、更新时间，以及最近语义消息摘要；正文读取使用 `sessionQuery.readSurface`，检查最近 80 条语义事件，每个摘要最多 2000 字符。
- v4 用户消息只接受真实用户来源，跳过 `dsh-time` 等运行时上下文；助理消息读取嵌套正文，跳过 reasoning（内部思考）块。
- 本地运行状态补充读取 `sessionController.list` 和 Agent 状态，`live` 只表示内存实例存在，不能证明正在运行。两个汇总入口都明确保留未知状态，不能据此宣称没有进展。
- 范围外与归档记录保留元数据用于高级诊断，其正文不读取。范围变化后返回当前范围元数据，不返回旧范围正文。
- 索引缓存与运行记录分离，失效不会删除上次完成记录。构建期间源数据变化时，完成结果保留但标记过期；版本持续递增。
- 记录保留本次 Host 运行期间最近 30 次，不跨 Host 重启持久化，不保存正文。重复使用缓存和刷新面板不制造索引记录。

## 原生模型问答

新增 `llm.text` 能力路由，调用 DSH `listProviders`、`listModels` 和 `stream`。本次只启用实际验证过的 DSH 0.2.1-alpha.1 协议，模型与凭据由宿主管理，优先选择 `agentDefaultModel.currentSelection`。无原生模型目录的外部 CLI 提供商不进入选择列表；无模型时提示先配置 DSH 模型。

模型事实材料只有当前索引条目、范围与版本，不包含排除会话或整个设置。字符串字段先脱敏再序列化，保留有效 JSON；提示明确区分事实与会话中出现的指令，未知状态和空摘要必须说明证据不足。

多轮历史按 v4 消息协议构造：用户消息使用无身份输入，助理历史带模型来源。按块索引合并文字增量，不重复追加 `block-end` 正文；检查 `finish` 中的失败、中止、工具请求和长度上限，保留部分文字与具体错误。

每轮最多 20 条历史，每条最多 8000 字符；索引事实最多 120000 字符，超限提示缩小范围。请求设置 2048 token 输出上限和 90 秒中止，轮次最多保留 30 条。关闭窗口、停止回复、模块释放或范围变化会取消生成；异步读取目录后再次核对范围与索引。切换范围、模型或索引版本后重开文字上下文。

问答不创建 Agent、项目会话或工具，不调用任务派发，不需要语音租约与麦克风。语音动作继续沿用原有规则路由。

## 接口与兼容

| 接口 | 含义 |
| --- | --- |
| `assistant/debug` | 元数据、索引新鲜度、当前范围的结果与运行记录 |
| `assistant/index/rebuild` | 手动执行正文索引 |
| `assistant/chat/models` | 原生模型目录和默认模型 |
| `assistant/chat/start` | 校验当前索引并启动只读问答 |
| `assistant/chat/read` | 轮询逐步生成的文字及终止状态 |
| `assistant/chat/cancel` | 中止请求 |

新增接口同时登记 `/codingns` 主 RPC（远程过程调用）通道和旧 `/api/codingns/*` 精确 HTTP 入口。既有 `assistant/preview`、`assistant/turn` 规则契约保留，新文字面板使用独立 LLM 路径。
