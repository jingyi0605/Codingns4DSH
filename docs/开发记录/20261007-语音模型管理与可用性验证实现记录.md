# 语音模型管理与可用性验证实现记录

日期：2026-10-07

## 问题与结果

原初始化窗口只提供模型下拉框和下载按钮，无法确认本地文件是否齐全、当前配置使用哪个模型，以及模型是否能完成识别。原初始化成功只代表路径已保存，不能证明原生模型可用。

窗口改为模型管理卡片，每个模型分别显示下载状态、当前使用标记和最近验证结果。支持刷新状态、查看四个文件的路径与大小、验证可用性、补全下载、切换使用和重新下载。成功后保留窗口展示结果，不再立即关闭。

## 状态与验证

- `assistant/voice/models` 只读取当前 Host 的模型文件与验证记录，不下载模型、不加载原生识别器。
- 文件状态分为未下载、文件不完整和已下载；四个文件都非空才显示已下载。该状态独立于验证通过或验证失败。
- 当前模型根据已初始化的 Sherpa 配置判断；已有自定义四文件路径仍可读取与验证，不强制迁移到默认缓存。
- 验证记录写入缓存目录的 `.validation.json`，包含时间、错误，以及文件路径、大小、修改时间和状态变更时间组成的指纹。文件变化后旧结果失效。该指纹用于使验证记录过期，并非官方 SHA-256 摘要认证。
- `assistant/voice/model/verify` 在独立 Node 子进程中加载同一份正式识别配置，输入两秒静音，执行解码并检查识别结果结构。无需麦克风或全局语音租约；原生模块异常退出不会终止 Host，超时或模块释放会结束验证进程。
- 验证通过表示模型能够加载并执行本地识别，不代表已经验证麦克风、扬声器或真实语音准确率。

## 下载、切换与修复

初始化与切换先准备文件、执行验证，再保存当前配置；验证失败保持原配置。下载拒绝空正文和已知长度不匹配的文件，失败关闭句柄后清理 `.part` 文件。保留原下载进度条，验证阶段显示独立的不定进度，不用下载的 100% 代替验证成功。

重新下载在独立临时目录准备整组文件，验证成功后才替换缓存目录；下载或验证失败保留旧缓存。目录替换失败恢复原目录，结束后清理临时目录。

Host 串行处理下载、修复和验证。实时对话运行时禁止切换与重新下载，允许独立验证；模型操作期间禁止启动新的实时对话。另一页面正在操作时，当前窗口显示占用提示并自动刷新。

## 前端样式

使用现有主题颜色、按钮和边框，模型卡片取代原生下拉菜单。顶部显示当前模型与实时运行状态；详情折叠展示文件位置。窗口主体可滚动，操作栏在窄屏折行，错误与成功反馈留在窗口内。状态尚未读取时显示待查询并禁用操作，不把未知状态显示为未下载。

## 验证与边界

- 通过源码加载器直接执行语音、模型、契约和模块接线回归：96/96 通过，无构建前置步骤。
- 新增覆盖：缓存状态、自定义路径、验证持久化与文件变化失效、原生子进程失败/超时/取消、修复失败保留缓存、切换失败保留配置，以及组件状态和操作按钮。
- 类型检查、国际化检查及差异格式检查通过。
- 组件服务端渲染检查通过；本地 HTML 浏览器预览被浏览器的文件协议访问策略拒绝，未进行实际页面视觉验收。
- 本轮未下载或验证用户真实缓存中的模型，未构建、启停或重启服务，未操作 Desktop，未提交或推送。实际界面及真实模型验收需要加载最新 Host 与 Client 产物后完成。
