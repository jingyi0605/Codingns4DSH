# PeerHost 原生派发启动就绪重试修复记录

## 问题

Stage0 启动时，Web Connection 可能先接收浏览器的 PeerHost 请求，而 DSH 的
`sessionController`、`workspaceController` 仍在等待依赖服务。Gateway 已经存在，
但调用会返回 `gateway/service-unavailable`，导致会话列表、模型目录和工作区订阅
在首轮加载中失败。

## 修复

`src/host/modules/peer-host/peer-host-native-dispatch.ts` 在调用 DSH Typert Gateway
时增加有限指数退避。只对 `gateway/service-unavailable` 重试 8 次，等待
`100/200/400/800/1600/3200/6400/10000ms`，总等待时间约 22.7 秒，覆盖 DSH
Connection 默认的 15 秒就绪窗口；请求取消时立即结束。参数错误、会话不存在、权限
错误等业务错误直接透传，不重复调用。

## 验证

- 增加 Service 稍晚激活后 unary 调用成功的测试。
- 增加业务错误不触发重试的测试。
- 未操作 Desktop，也未启动或重启 Stage0。
