# 助理输入栏附件与斜杠指令优化记录

日期：2026-10-07

## 本次结果

日常输入栏改为左侧添加附件、中央自动增高输入框、右侧电话通话与圆形发送／停止。移除输入框拖拽手柄、内部边框和蓝色焦点描边，保留按钮的键盘焦点提示；消息区仍独立滚动，输入栏固定在窗口底部。标题的配置／返回对话和关闭也改为图标按钮。

压缩、清理图标及其工具栏组件已删除。正常连续轮次复用 DSH 原生 Agent，由宿主的压力阈值和上下文溢出机制自动压缩；不再每九轮强制重建 Agent。可见历史取消 200 条消息硬上限，仍保留原存储的 4,000,000 字符保护。自动上下文压缩不删除显示记录，旧手动压缩接口继续兼容。

发送 `/clear` 可清理交流，兼容 `/清理`、`/reset`、`/重置`。输入 `/` 后出现候选，选择候选只填入草稿；实际发送后弹出一次确认，确认后清理消息及摘要，保留配置和项目索引。完整重置仍只能从「配置 → 更多设置」进入并确认两次。

## 输入与图标

- textarea 每次先归零高度再测量 scrollHeight，内容删除后也可缩回单行；达到 min(120px, 20dvh) 后内部滚动。窗口、输入宽度及软键盘视口变化时重新测量。
- Enter 发送、Shift+Enter 换行，中文输入法确认不发送。禁用状态不能添加附件、提交、重复停止或执行指令。
- 添加、设置、关闭、发送、停止复用 DSH 图标；返回对话按用户后续澄清使用普通三点气泡，保留返回已有对话的行为。当前宿主只提供带加号的新对话图标，普通气泡复用其轮廓与 Regular 线宽，不使用发送箭头或信息圆圈。当前宿主缺少电话图标，听筒采用相同 16px 画布、Regular 线宽、圆角和 currentColor，未来宿主提供原生电话或普通对话图标时自动使用。
- 标题与附件移除按钮使用同一悬停和按下主题色；电话与发送保留原实时启停及生成取消链路，所有按钮都有可访问名称和悬停提示。蓝色发送按钮使用白色前景，修正暗色主题下蓝底黑箭头。

## 附件链路

1. 文件选择或粘贴图片只加入 Client 草稿，可单独移除，不提前上传。仅有附件也可发送；发送失败保留文字及附件。
2. 每条消息最多 6 个，单个 10 MiB，合计 20 MiB；图片支持 PNG、JPEG、WebP、GIF。发送时才读取 File 字节并编码，经正式 conversation/start 接口传递。
3. Host 在接收前校验名称、编码、数量和大小，不接受浏览器指定 Host 路径或已有附件引用。图片委托 DSH 的 admitPromptContent 验证和归一化，普通文件委托 admitEncodedFile；仅原生生成的 sha256 引用进入正式消息和持久记录。
4. 图片以原生图片消息交给模型。文本文件通过 assistant_read_attachment 工具读取，仅允许本助理已经收到的附件标识，不开放任意本地文件读取，最多返回前 128 KiB 的 UTF-8 文本。工具不执行代码，也不增加子 Agent 权限。
5. 上传内容指纹参与请求去重。取消先于启动、上传中取消、清理、重置及范围变化时，迟到结果不得启动模型或写入消息；同一请求 ID 不能换附件重新提交。调试文本接口不能注入已有附件引用。
6. 持久历史只保存引用和名称，不保存 Base64、原始文件或用户提供的 Host 路径。刷新与跨文字／语音追问保留最近历史中的引用，清理后的新轮次不再向模型提供旧附件。

图片理解需要模型支持视觉；当前不解析 PDF、Office 等二进制文档。清理解除交流中的引用，不删除 DSH 原生附件存储中的对象。原生接收没有逐文件撤销接口，取消会阻止模型及记录回写，已经接收的不可变对象由宿主管理。
