# 远程工作区移除按钮实现记录

## 需求与判断

“选择工作区目录 → 远程 HOST”中的已添加表格缺少取消添加入口。本次在表格最右侧增加“操作”列，每行提供“移除”按钮。

复用现有 `setWorkspaceVisibility(peerHostId, workspaceId, false)` 接口，仅修改当前用户登记的可见工作区集合，不删除远端目录、工作区或会话，不新增服务端接口。

## 实现

- 添加与移除共用可见性保存逻辑，保存成功后同步 Host 记录、表格与候选列表；移除后可立即重新添加。
- 保留其他已添加工作区；移除最后一行后显示空状态。
- 聚合降级时按原可见 ID 集合保留已有行；候选暂时为空时，使用已加载的聚合行恢复可添加候选。
- 保存期间禁用添加、移除和 Host 切换，并以函数守卫阻止迟到的重复点击。
- 保存失败保留原记录并展示真实错误；成功后通过既有聚合刷新机制更新侧栏，刷新异常不覆盖保存成功状态。
- 补齐中英文词条、按钮无障碍名称和主题样式；为操作列保留固定宽度，路径继续截断显示。
