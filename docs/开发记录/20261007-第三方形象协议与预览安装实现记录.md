# 第三方形象协议与预览安装实现记录

## 实现结果

默认提供鱼妞、鱼仔及用户已安装的形象。形象管理提供第三方使用说明和勾选操作，同意后加载十二条目录记录并合并进「当前形象」同一个下拉列表，第三方名称旁显示独立蓝色标签，不再使用独立目录选择列表。已安装形象直接切换；选中未安装条目后自动临时下载完整素材，在右侧形象区域加载真实形象，不需要单个形象许可确认或手动下载按钮。临时预览不改变实际角色，下载及模型准备只在预览位置显示动画，切换或关闭后自动清理，失联以心跳超时回收。只有正式采用时才需确认该形象许可，并复用已下载素材；完整安装及设置保存成功后才登记启用，同一 ID 不出现重复选项。切换预览清空许可勾选，取消或失败保持实际选择。

协议版本与同意时间保存到 `appearance.thirdPartyConsent`；旧设置不会自动同意，刷新保留当前版同意记录，版本变化需重新确认。关闭目录删除同意记录，保留已安装素材和当前角色。旧 URL（网址）安装及扩展接口继续兼容。

## 数据和接口

- `assistantAvatarChoices` 只合并展示选项，目录条目沿用安装后的 `catalog-${id}` 去重，保留用户命名及旧预设。元数据不写入 `appearance.models`，不会占用自定义形象容量。协议关闭后只隐藏待安装目录项，已安装角色继续可选。
- 选项来源单独保存在 `thirdParty`，不从名称后缀推断。当前项和菜单行共用蓝底白字标签；创建页复用选择器，保留未登记旧预设的初始化回退及不可用草稿。菜单复用 DSH `Menu` 的键盘导航、焦点归还与关闭行为，弹层避开滚动裁剪并置于助理窗口上方。
- 目录请求和暂存预览绑定协议版本与同意时间，关闭、协议变化或卸载取消请求并隔离迟到结果。预览按角色、素材版本及本次选择挂载，切换即清空许可；自动预览下载不锁定选择入口，正式采用期间才锁定。停止或失败后重新选择同一条目即可再次自动预览。
- `avatar-packages/catalog.json` 与十二份原生安装清单仅保存元数据，加入 npm 文件白名单；图片、图集、模型、动作和引擎不随包提供。页面读取本地清单，不依赖尚未推送的 GitHub 文件，原 GitHub 文档链接继续保留。
- `AssistantAvatarCatalog` 校验目录身份、原生清单和固定上游素材版本，读取元数据时没有外网请求。目录安装复用 `AssistantAvatarPackages.installManifest`，原 URL 安装也调用相同适配器和原子素材安装流程。
- 管理器新增 `setThirdPartyEnabled`、`getCatalog`、`previewCatalog` 和 `installCatalog`。Host（宿主端）对预览与采用均校验当前协议、写入权限和条目版本，仅正式采用校验 `licenseAccepted`；安装后和 Client（客户端）登记前再次确认状态，设置拒绝或迟到结果只回收本次未使用的新素材。
- 原静态小图 GET（读取请求）入口 `/api/codingns/assistant-avatar-catalog-preview` 保留兼容，当前界面不再请求宣传图；原有 1 MiB 图片签名校验及八项缓存限制继续有效。
- 临时下载复用完整素材安装器和独立系统临时目录，通过租约读取本地模型及全部依赖。临时插槽禁用持久预览及头像缓存，采用时原子复制正式副本，不再次下载。正常释放立即清理，失联后最迟在三分钟有效期加三十秒扫描周期内回收；Host 模块停用清理全部预览。实际 Live2D 仍要求 Host 已安装外部引擎。

## 2026-10-07 HTTP 正常完成误取消修复补充

用户反馈大肥鱼 Q 版全身预览显示 `This operation was aborted`。通过真实隔离 HTTP 通道复现，错误来自 Host RPC（远程过程调用）将 `request.close` 无条件映射为取消。Node 的请求对象在请求体接收完成后也会触发该事件，异步下载因此在刚进入处理器时便被取消。上一轮回归直接调用 Host 功能处理器，未覆盖这个传输生命周期，因而未发现问题。[Node HTTP 官方事件说明](https://nodejs.org/download/release/latest-v25.x/docs/api/http.html#event-close_3)记载了该完成语义。

修复后，请求端只在 `request.complete` 为假时取消；响应端在 `response.writableFinished` 为假便断开时取消。正常收完请求体及正常完成响应均不会中断下载或有效租约；用户发送完请求体后主动取消响应仍会中止下载并清理素材。图片和动作图集的通用错误提示不再带 Live2D 引擎说明，只有实际 Live2D 渲染失败才提供对应引擎提示。

新增真实 HTTP 正常完成及中途断开两项回归，修复前复现同样报错，修复后全部通过。7 份相关源码回归 **72 项，71 通过，0 失败，1 项因缺少可选 Live2D 引擎跳过**；全仓 noEmit 类型、国际化（1440 键、0 阻断）及空白检查通过。另使用实际目录清单和默认下载器联网获取大肥鱼 Q 版全身图集，共 **1,190,494 字节**，临时资源入口返回 **200、image/webp**；释放租约后隔离临时目录为空。此项验证证明真实素材下载及同源读取正常，不替代实际页面绘制验收。
