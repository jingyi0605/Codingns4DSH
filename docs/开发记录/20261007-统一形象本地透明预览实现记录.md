# 20261007-统一形象本地透明预览实现记录

对应 Spec014 阶段 10。用户在阶段 9 评估后明确要求实施。

## 实现结果

统一插槽现可持久化成功绘制的透明静态预览。内置 Live2D 成功显示后自动保存；刷新或再次载入同一形象时，先从 IndexedDB（浏览器数据库）读出本地图片并显示，底部保留小型动态加载反馈与真实进度条。后台完成真实绘制后，预览淡出、动画淡入。首次使用、没有有效缓存或本地存储失败时，继续显示原有完整加载效果。

悬浮与对话插槽复用同一接口，各自保存对应位置的预览，包适配器继续负责模型和素材配置。正式环境的缓存数量、下载次数、耗时和调试提示仍关闭，仅 dsh-stage0 显示；预览不改变真实加载状态，也不替代 WebGL 初始化。

## 统一数据与接口

新增模块：`preview-store.ts` 负责数据库与缓存键；`preview-capture.ts` 负责有效画布捕获；`preview.ts` 负责插槽读写和临时图片地址生命周期。

渲染器注册项声明 `previewVersion` 与 `reportsLoading: true`，组件接收可选 `onPreview` 回调，提交 `{ blob, width, height }`。公共 `AssistantAvatarPreview` 类型和 `captureAssistantAvatarPreview` 函数从 Client 入口导出；其他引擎也可自行生成预览。旧扩展不声明时保持原行为，统一插槽没有按渲染器 ID 判断的特殊分支。内置 Live2D 已接入，图片和精灵图维持原加载流程，未增加跨域请求。

缓存键包括格式版本、角色 ID、展示位置、渲染器与捕获版本、绝对资源地址、图集版本、构图和排序后的状态映射。形象、模型路径/版本或构图变化使用新键；等值配置复制、名称和显示尺寸变化不必重新生成键。写入时清理同一角色/位置的旧版本；删除自定义形象后清理两种位置的预览。

| 规则 | 限制 |
| --- | --- |
| 文件格式 | 非空 PNG，保持源画面透明通道 |
| 最长边 | 512px |
| 单张文件 | 512KiB |
| 数量 | 最多 8 张，PNG 合计不超过 4MiB |
| 有效期 | 30 天，成功显示后更新 |
| 开库与事务 | 各 1 秒超时，失败不阻断模型 |
| 捕获等待 | 最多 1 秒，失败仍显示真实形象 |

浏览器清理网站数据、隐私模式清理存储或禁止 IndexedDB 时，没有预览可恢复；动画与进度条继续工作。缓存只保存图片，不是模型文件持久缓存。

## 关键生命周期

1. 插槽启动并行读取本地预览与初始化渲染器，不等待数据库再加载模型。有效缓存先显示，仍保持 `aria-busy=true` 和真实文件进度。
2. Live2D 的 loaded 事件不保证画面像素已经出现。捕获函数临时观察当前 WebGL 上下文的绘制调用，在同帧同步绘制结束的微任务中拷贝完整画面到有界 2D 画布，再异步编码 PNG，不启用 preserveDrawingBuffer（保留绘制缓冲）。
3. 全透明空帧不保存，跨域像素读取失败只跳过预览。获取有效画面、超时或取消后立即还原绘制观察函数；PNG 编码期间不干扰后续动画，迟到编码结果不能提交。
4. 插槽负责写入数据库与淡入交接，不等待落盘才显示动画。已有缓存图片保持同一 src 直到淡出，避免 PNG 再解码造成交接闪白。旧读取不能覆盖新捕获，损坏缓存图片会清理且不阻断模型。
5. 每个键使用 AbortController（异步取消控制器）隔离读取和写入；切换形象或插槽卸载时取消旧读写，Live2D 隐藏时另取消其帧捕获。临时 Blob URL（文件数据对象的图片地址）在插槽卸载时释放。失败回退原有机器人与用户提示。

没有新建 Service Worker（后台请求处理器），没有修改 DSH 缓存、Profile、运行进程或模型美术素材。

## 独立浏览器证据

使用 Microsoft Edge 的独立无头临时实例。React 与所有插件模块来自已安装依赖和仓库源码，只在内存转换模块；请求由测试专用路由直接调用源码 Handler（资源处理函数），不启动 HTTP 或开发服务器，也不产出 Client 构建文件。

- 真实大肥鱼 Live2D 首次成功绘制，保存 240×260 PNG，54,761 字节。解码像素中透明像素 35,705 个、有效像素 26,695 个，确认没有缓存空帧且保留透明背景。
- 整页刷新后人为延迟引擎入口 1.5 秒：缓存图片在引擎准备阶段可见，底部轨道动画和进度条仍存在。截图已检查，效果见测试图片 `/tmp/codingns-avatar-preview-restored.png`。
- 真实模型就绪后：预览 opacity 为 0、加载占位消失、实时 canvas 存在。正式环境诊断请求为 0，调试摘要不存在，脚本错误为 0。
- 使用真实 IndexedDB 验证 30 天过期、超过 8 张淘汰最早项、保留最新项、同一角色/位置的旧版本替换，以及删除角色后两种位置一起清理，全部通过。

这些证据属于隔离测试，不是用户当前运行页面或 npm 发布产物验收。
