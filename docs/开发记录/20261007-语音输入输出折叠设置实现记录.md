# 语音输入输出折叠设置实现记录

## 用户行为

声音管理保留顶部的一键初始化向导，下方为默认收起的两张卡片：

- **语音输入**：麦克风设备、语音识别模型、模型下载与验证。
- **语音输出**：浏览器支持时的输出设备、播报后端、合成试听、语速和音量。MOSS 模式另外显示音色、导入和高级播报参数。

卡片使用统一图标、圆角、间距、主题颜色与展开箭头，标题下显示模型或音色摘要。两组独立展开；初始化完成不会强行展开设置。鼠标和键盘均可操作。

## 实现

`AssistantVoiceSettingsGroup` 使用原生折叠组件，折叠时保留子组件实例和草稿，将活动状态传入识别、设备与音色组件。收起输出会停止合成试听；已发起的模型下载继续完成。后续已按用户要求移除参考音频播放器与试听文本字段，详见[音色试听与后端设置精简记录](20261007-音色试听与后端设置精简记录.md)。

麦克风与输出设备分别枚举，收起后停止设备监听和闲置查询。首次向导进行中锁定两组内部控件，卡片仍可展开查看。识别模型和音色编辑器继续复用原服务、参数保存与验证逻辑；旧模型弹窗保持原外观。内嵌编辑器去掉重复外框和多余留白。

## 验证

- 工作台、初始化向导、折叠状态、模型展示、初始化 RPC（远程过程调用）及播报输出定向测试 **45/45** 通过。
- 类型检查和差异检查通过。国际化仍有 `peer-host.ts:96` 的一处既有导航日志阻断，本次新增文案已补齐中英文词典。
- Playwright（浏览器自动化工具）加载源码组件生成的静态页面：600px 暗色折叠、390px 暗色输入展开、390px 明色输出展开均无横向溢出，截图已逐张检查。
