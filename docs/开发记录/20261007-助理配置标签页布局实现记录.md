# 20261007-助理配置标签页布局实现记录

本记录描述标签拆分时的实现和验证。后续已删除工作台试聊/问候试听及其专用测试，并调整尺寸、协议与模型入口；当前行为和 110 项回归见[助理页面精简与形象管理优化记录](20261007-助理页面精简与形象管理优化记录.md)。

## 结果

创建后的助理配置改为四个标签页，默认打开「基本信息」，只显示当前页的设置，不再把资源管理塞进同一页的折叠区域。首次初始化仍保留名称、模型、性格背景、形象四项简洁表单及预览。

| 标签页 | 内容 |
| --- | --- |
| 基本信息 | 名称、对话模型、性格背景 |
| 形象管理 | 鱼仔/鱼妞和已登记形象选择、悬浮/对话显示与尺寸、形象包安装和自定义素材 |
| 声音管理 | 浏览器/MOSS 声音选择、输入输出设备、MOSS 安装、音色与播报参数、试听和参考录音导入 |
| 更多设置 | 关联项目、语音识别模型、索引/对话提示词、索引调试和助理维护 |

前三页共用预览，更多设置隐藏预览并使用全宽布局。窄屏时表单与预览上下排列，标签栏可横向滚动；选中标签有主题高亮，支持方向键、Home 和 End 切换，以及标签和内容区的无障碍关联。

配置中的清理、压缩和重置入口仅在更多设置显示，日常对话保留原维护入口；切换标签取消尚未执行的维护确认。

## 状态与保存

基本信息、项目和声音选择仍共用父级草稿与统一「保存配置」，切换标签不清空草稿。形象管理继续复用原编辑器，选择和显示设置通过原管理器独立保存；安装资源、音色、播报参数、设备及提示词的保存方式沿用原逻辑，界面说明区分保存范围。

未访问页面不挂载编辑器；访问后隐藏保留实例和稳定的页面标识，避免丢失形象安装地址、音色导入或参数草稿，也不因切换页中断正在安装的资源。离开声音页停止合成试听及原录音播放，保留表单。共同预览和正式对话仍保持隔离。保存、取消返回对话或重置时恢复默认标签，重置后继续使用简洁初始化。

项目和声音字段已拆开；原能力表单入口保留兼容组合，不用于新的多页界面。声音页缺少 MOSS 时仍仅允许浏览器输出，不隐式安装依赖；只读或尚未加载的设置保持原有禁用规则，标签本身可浏览。
