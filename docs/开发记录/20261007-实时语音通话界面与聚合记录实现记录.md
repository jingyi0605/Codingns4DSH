# 实时语音通话界面与聚合记录实现记录

日期：2026-10-07。对应 spec013 与 spec013.1 需求 7、阶段 8。

## 完成的功能

1. 首次初始化与模型选择默认中英双语实时模型 `sherpa-onnx-streaming-zh-en`，模型文件约 200 MB，支持编程交流中的中英文。中文轻量与 Large 仍可选择，已有模型和手工路径不覆盖。只打开声音管理不会下载或切换模型。
2. 点击聊天输入栏电话图标进入专用通话页，展示当前助理形象、状态、计时和底部实时文字；提供扬声器、麦克风静音、挂断三个圆形控制。挂断返回普通聊天。
3. 每次通话结束后，聊天流用一张语音沟通卡片替换对应气泡，显示有效发言条数和时长。点击原生模态框查看全文、打断标记和工作区／联网搜索／附件等能力调用记录。

## 数据与执行链路

- `AssistantVoiceSession` 保存通话 ID、Host 开始与结束时间以及消息；连续消息新增可选 `voiceSessionId`，工具摘要通过可选 `toolCalls` 附在助理消息上。通话副本与普通历史共用原有原子存储文件和 4 MB 上限，按 UTF-8 字节检查容量并预留单轮空间，保存错误显式反馈。
- Client 在 `voice/start` 传独立通话 ID，Host 成功获取租约后创建记录；`voice/stop` 先归档已完成答案、已识别输入和已生成残句，再停止租约。租约失效也归档，旧结束通知不能关闭新通话。
- 新话语打断旧回复、模型目录尚未返回、模型启动失败时，已识别输入仍保留。半轮文字只进入通话详情，不伪造完整问答加入后续模型历史；异常长残句沿用已有每条 16000 字符上限，确保归档可恢复。迟到模型输出不能重复归档。
- `tools/execute` 与 `tools/result` 采集实际工具开始和最终结果，仅观察本助理会话；不改工具实现、权限或搜索提供商。分类为工作区能力、联网搜索、附件读取，保存成功／失败／取消状态、时间、参数与结果摘要。每轮最多 24 条，参数最多 4000 字符，结果最多 6000 字符，遮蔽常见凭据字段及字符串。
- 模型上下文压缩不删除通话副本，清理交流才删除卡片；没有新增字段的旧存储可恢复。Host 重建时结算遗留通话，结束时间按最后发言估算，避免遗留记录永久显示通话中。旧客户端未传 ID 时保持原来的语音消息展示。
- 发言条数按非空用户／助理消息计数，工具结果与空答案不计入；不按标点拆成多条，也不保存原始录音。

## 音频控制与展示

麦克风静音同时关闭音轨、上传零值 PCM（脉冲编码调制音频）并过滤识别输入，保留帧序号、采集时钟与租约；取消静音沿用本次通话。MOSS 通过音量节点静音而不重启推理或播放时间线；浏览器音色静音时结算当前播报并取消声音，后续段跳过。

扬声器弹出面板支持关闭声音；只有 MOSS 后端及浏览器支持 `AudioContext.setSinkId` 时才允许切换物理播放设备。浏览器 `speechSynthesis` 使用系统默认输出，不显示之前 MOSS 的设备选择为当前输出。

通话页沿用 DSH 明暗主题及当前形象插槽，限制小屏形象高度，支持减少动画的系统偏好。长字幕滚动到最新一行；字幕来自识别与大语言模型的增量文字，不是与音频逐字对齐的字幕。详情使用原生 dialog，Escape 只关闭详情，参数与结果以转义文本显示。
