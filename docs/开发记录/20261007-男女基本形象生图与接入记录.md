## 接入与兼容

初始化与创建后的形象管理共用两项基本选择，对话和悬浮展示共用图片渲染器与真实加载反馈。女生保留旧默认 ID 与存储结构，名称按用户要求更新为「鱼妞」，男生为「鱼仔」。写入仍接受旧内置名称，读取归一化为新名称，不放开素材或其他身份字段的替换；读取时自动补男生选项。清单上限从 20 改为 21，保留原有 19 个自定义形象名额，两项基本形象均不可覆盖或删除。

PNG 随插件包提供，Host（运行插件的主机）只登记两条固定 GET 图片路由。首次请求才读取随包文件，后续请求复用缓存；query（网址查询参数）不能改读取路径，未知路径返回 404，非 GET 返回 405，读取失败可重试。图片 URL 带 `v1`，更换图片内容时应更新文件名与 URL 版本，避免旧缓存继续命中。`package.json` 明确包含 `assets/assistant-basics/*.png`。

基本图片无需第三方素材安装、Live2D 或 MOSS。大肥鱼外部模型仍按用户选择安装，未登记的旧预设不补入首次创建清单。未创建助理时仍不显示悬浮形象。没有构建、启动 Stage0、操作 dsh-web 或 Desktop，也没有安装已清理的外部依赖。
