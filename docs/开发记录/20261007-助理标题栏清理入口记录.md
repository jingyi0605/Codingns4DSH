# 助理标题栏清理入口记录

日期：2026-10-07

## 实现

日常对话标题栏在配置按钮左侧新增清理按钮，使用 DSH 原生重置箭头、32px 按钮和 20px 图标，沿用配置按钮的主题色、悬停、焦点、可访问名称和提示。按钮名称为「清理对话」，只在已创建助理的日常对话中显示，读取完成前和操作中禁用。

点击按钮只调用 requestClear 打开一次清理模态确认，与斜杠指令共用该入口。确认后经既有 maintain('clear') 停止当前生成和语音，调用 conversation/clear，清空助理消息、交流摘要和输入草稿；配置及项目索引保留。取消不调用清理接口，执行期间禁用重复操作，失败留在当前模态框反馈。完整助理重置继续位于更多设置，经两次确认执行。

修改 assistant-workbench.ts 和 primitives-adapter.ts，更新现有工作台及确认控件测试；同步 README 与 spec013.1 的需求 3.15、4.6、设计 §4.1 和任务 6.13。
