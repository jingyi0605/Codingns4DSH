# Live2D 引擎安装恢复与跨平台验证记录

## 问题与原因

用户反馈安装 Live2D 引擎失败，临时形象预览请求 `/api/codingns/assistant-avatar-runtime?v=2.1.1` 及重试地址连续返回 503。该状态只说明运行时读取失败，不能单凭它判断下载或解压失败。

本会话确认并修复以下问题：

1. 目录条目选择提前返回，直接挂载临时预览，绕过已登记角色使用的引擎检查。
2. 配置窗口将引擎许可保存在草稿中，安装请求却没有携带许可，Host 只检查正式配置而拒绝首次安装。
3. 安装成功只清除模块加载缓存，已经进入错误回退的形象插槽不会重新挂载。
4. 引擎状态查询未绑定窗口生命周期，窗口关闭后的迟到答复仍可触发安装或选择。
5. 快速重复重试只受 React 状态刷新约束，可能同时排入多份安装，而取消控制器只对应最后一份。

日志中的 `changes.summary` 404 和 `/plugins/events` 错误未在本会话处理。

## 修改内容

### 许可传递与预览准备

- 目录中的 `cubism-model`、`dsh-live2d-pet`、已登记 Live2D 角色和旧预设共用引擎检查；引擎就绪后才挂载新预览。
- 安装请求携带当前 `engineConsent`，Host 校验版本与时间，只授权本次安装，不提前保存整份配置。
- 未携带许可的旧客户端仍可使用正式配置中已保存的记录；非法、过期许可和只读连接继续被拒绝。
- 安装纳入配置窗口的资源准备状态，期间禁用保存；取消后不采用迟到结果，未就绪答复不能误报成功。

### 安装后的形象恢复

- 安装完成通知形象插槽，重新挂载 Live2D 的错误边界与内容状态。
- 其他渲染器保持原实例；模块加载器继续使用新地址绕过失败的动态导入缓存。

### 取消与重复重试

- 引擎状态查询使用独立取消控制器，窗口卸载或新查询取消旧查询，采用答复前再次检查取消及挂载状态。
- 同步检查安装控制器，阻止 React 刷新前的重复请求，取消始终对应唯一进行中的安装。
- 失败保留待执行的选择，成功执行选择后才清除，支持直接重试。

## 验证结果

- 首轮安装、运行时、渲染器、草稿、临时预览、第三方目录和工作台回归：88 项通过。
- 跨平台复核前新增的 3 项竞态测试全部失败，分别复现两种迟到状态误执行与重复重试请求；修复后全部通过。
- 跨平台复核覆盖引擎流程、平台边界、安装、运行时、渲染器、配置草稿和共享语音解压器：56 项通过、0 失败、0 跳过。
- `pnpm run typecheck` 与 `git diff --check` 通过。

### macOS 实际验证

在 `darwin/arm64`、Node.js `v22.22.0` 上，在仓库临时目录完成固定 npm 下载、SHA-512 摘要校验、系统 `bsdtar` 解压、损坏副本替换及就绪副本复用。真实入口文件为 838,352 字节；HTTP 和 `dsh-app://app` URL 在运行时路由处理函数中均返回 200 和完整 JavaScript 内容。

### Windows 验证边界

已验证系统解压器选择、大小写环境变量、盘符、UNC（网络共享）路径、中文空格和参数传递逻辑。Windows 使用系统 `tar.exe`，避免 Git PATH 中的其他 tar 干扰；命令直接传参数数组，不经过 shell。

Windows 的系统 tar 基于 `bsdtar`，参数兼容性参见 [Microsoft 官方文档](https://learn.microsoft.com/en-us/windows/tar/)。隐藏控制台、子进程取消及退出处理参见 [Node.js v22.22.0 子进程文档](https://nodejs.org/download/release/v22.22.0/docs/api/child_process.html)。

本会话没有 Windows 实机执行记录，也未验证 Desktop GUI、协议转发和 WebGL 渲染。逻辑测试通过不等同于 Windows 实机验收。

## 复用测试与操作范围

平台测试位于 `tests/assistant-avatar-engine-platform.spec.ts`。显式设置环境变量 `CODINGNS_LIVE2D_NETWORK_TEST=1` 后执行以下命令可包含真实联网验证；未设置时仅跳过联网项。

```bash
node --import ./tests/register-source-loader.mjs --test tests/assistant-avatar-engine-platform.spec.ts
```

测试在内存加载源码，不执行构建。平台测试产物仅写入仓库 `data/live2d-platform-*` 独立目录，结束后已确认零残留。未启停 Stage0，未操作 Desktop、dsh-web 或用户 Profile，未推送或发布。
