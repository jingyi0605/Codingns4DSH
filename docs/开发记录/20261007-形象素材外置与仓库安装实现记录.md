# 20261007-形象素材外置与仓库安装实现记录

## 结果与数据边界

新配置只内置 CodingNS 机器人。第三方形象素材不进入插件源码或 npm 包，通过设置中的「安装形象包」从仓库或资源 URL 下载到独立目录，完整安装后登记并启用。源码保留通用适配器、渲染器和原始机器人；两个旧预设的元信息与固定资源表仅在 legacy 兼容模块中保留，用于已有选中配置，新配置不列出或登记其专用路由。

来源适配器（Source Adapter，来源发现接口）、格式适配器（Format Adapter，清单转换接口）、素材适配器（Material Adapter，依赖安装接口）和渲染器分别管理。所有注册表使用同一稳定快照机制，保留内置通用条目，支持幂等注销；已经安装的素材不依赖其导入适配器继续存在。Client 与 Host 各自按 services 隔离。

默认目录为 `~/.config/codingns4dsh/assistant-avatar-packages`，可由 `CODINGNS4DSH_STATE_DIR` 指定父目录。此目录独立于源码、构建产物和 DSH Profile。本轮只在临时目录验证安装，没有写入用户默认素材目录或 Desktop Profile。

## 安装与兼容

1. 输入 GitHub 仓库、目录或文件 URL，或 HTTP(S) 清单、模型、图片原始 URL，查找候选。
2. GitHub 分支/标签定位到提交；从候选中选择形象，适配 CodingNS、Codex pet.json、DSH Live2D pet.json 或 Cubism 2/3 模型。
3. 并发最多 4 项下载完整依赖并按来源去重，重写模型引用后原子写入完成目录。
4. 内容版本写入包元信息，Client 持久清单保存成功后选中新角色；两个展示位置共用原插槽。

完整保留贴图、模型、物理、姿态、用户数据、显示信息、表情、动作和音频，不把旧大肥鱼的专用清单裁剪应用到其他模型。l2d 通过字符串拼接目录加载资源，所以模型 JSON 中使用同目录相对素材入口。资源地址含内容版本，预览缓存自然按新版本失效。

新配置只登记运行时、素材、缓存状态三个固定 GET 入口。素材只能通过完成记录中登记的文件键读取，不开放任意磁盘路径或 URL 代理。安装不携带宿主凭据，逐次验证重定向和公开地址，拒绝私网、本地地址与脚本素材；兼容域名形式的 Fake-IP 代理。每包最多 256 文件/256 MiB，单文件 32 MiB、JSON 2 MiB；下载失败、取消和模块停用均终止未完成安装。

设置保存拒绝时清理本次未使用的新素材。移除角色清理透明预览，卸载前检查 Host 权威配置，防止删除其他角色仍使用的版本。旧 URL 配置和 `importPackage` 外链 API 保留，新的 `installPackage` API 才负责本地素材安装；已有选中旧预设继续显示并可迁入本地安装。

第三方插件的脚本、换装 UI、会话气泡、亲密度、语音和 Desktop 窗口不属于素材适配。其他仓库平台需要原始资源 URL 或来源适配器；私有仓库认证、压缩包与本地文件上传未接入。本轮没有安装完整第三方插件。
