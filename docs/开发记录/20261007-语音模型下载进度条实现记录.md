# 语音模型下载进度条实现记录

日期：2026-10-07

本文记录下载进度功能的第一阶段。后续模型管理窗口增加独立可用性验证，并在成功后保留窗口展示结果，见[模型管理实现记录](20261007-语音模型管理与可用性验证实现记录.md)。

## 用户要求与界面变化

全局语音助理的模型初始化弹窗原来只显示正在下载的文字。现在提供原生进度条，显示当前下载文件的序号、文件名、百分比，以及已下载大小与文件总大小。

百分比属于当前文件，文件切换时重新从零开始；文件序号说明整个模型的下载进展。服务端没有提供可靠的文件大小时，显示不定进度条和持续更新的已下载大小，不用文件数量估算字节百分比。下载结束后显示“模型已下载，正在初始化”，设置保存和运行时配置完成后才关闭弹窗。

## 实现方式

- `src/shared/voice-models.ts` 定义检查、下载、初始化和完成四个阶段，以及当前文件序号、字节数和可为空的总大小。
- `src/host/features/voice-model-setup.ts` 通过可选回调报告进度，现有调用继续兼容。下载量按实际写入文件的分块累计；压缩正文的 Content-Length（响应长度）不作为解压后模型大小。完整分块写入后继续沿用临时文件改名和缓存复用流程。
- `src/host/features/global-voice-rpc.ts` 为初始化保留最近一次进度快照，通过 `assistant/voice/setup-progress` 查询。请求 ID 隔离不同页面；下载或初始化期间拒绝重复初始化和启动实时语音，避免临时文件冲突或保存期间切换运行时。
- `src/host/rpc.ts` 补齐旧版 `/api/codingns/` HTTP 精确入口的查询路由，浏览器主入口继续使用已有通道。
- `src/client/voice-model-setup-progress.ts` 复用 RPC（远程过程调用），每次查询返回后等待 300 毫秒再查询。初始化结束或组件卸载时取消在途查询、清理计时器，并丢弃迟到响应。
- `src/client/features/voice-initialization-dialog.ts` 使用原生 `progress` 元素，沿用宿主主题颜色和中英文词典；下载期间继续禁用模型选择与操作按钮。
