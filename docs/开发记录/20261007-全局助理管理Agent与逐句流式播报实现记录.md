# 全局助理管理 Agent 与逐句流式播报实现记录

日期：2026-10-07。对应 spec013 管理 Agent 扩展及 spec013.1 共享持久对话。

## 改造结果

正式文字和实时语音改用同一个独立管理根 Agent（智能代理）。它运行在现有 DSH Host 中，使用专用空目录及会话级只读沙箱，默认简短口语回答。配置、模型和工具约束只注册到助理作用域，不改变其他会话或 Host 默认。

四个工具分别为工作区列表、会话列表、有限正文摘录和管理跟进。继承工具全部隐藏，原生模式移除程序化工具传输，执行白名单继续拒绝隐藏或额外工具。助理不能创建子 Agent、运行命令、访问项目文件或修改代码。查询不唤醒目标；管理跟进默认通过现有原生消息入口排队，发送前核对当前范围、归档状态、完整 Host／工作区／会话标识、索引代次和更新时间，并按工具执行 ID 去重。返回 accepted（已送达）不能称为工作完成。

跟进消息限定管理用途，不新增编码执行任务。目标 Agent 仍按自己的模型和执行权限处理消息，助理不会替它修改沙箱或禁用思考；纯状态读取不进入目标执行轮次。

模型使用已公开的 off／none（关闭思考）值；支持思考但不能关闭的模型明确拒绝。没有思考能力的普通模型不发送额外参数。每步最多 1024 输出 token（模型文本单位），每轮最多八步和十二次工具调用，默认回复一到两个短句、100 字以内。索引服务保留原有独立模型任务及预算，项目整轮完成后五秒增量更新。

## 历史与取消

Host 现有共享对话存储继续作为历史来源。连续问答复用运行实例；九轮后、模型切换、压缩、清理、范围隔离或失败后，从近期问答和摘要重新建立受限实例。Host 重启恢复原有交流记录，重新创建运行实例。助理自己的原生会话 ID 使用专有前缀，项目索引排除这些记录。

文字和语音均使用原有请求 ID、取消和超时控制。原生驱动退出、模型正常结束后才将成功问答保存；取消与失败不记为完成。索引缺失时允许普通交流及管理工具查询。最新工具状态优先于旧索引，历史聊天不能覆盖当前事实。

## 逐句流式播报

Agent 流事件只向客户端投影可见文字，不投影思考、工具参数或结果。客户端消费累计文字快照；遇到中文句尾标点、英文句点加空白或换行时立即排队。模型尚未结束即可开始第一句；模型结束后补播剩余残句。小数及网址不拆分，重复快照不重读，待播队列最多 32 句。

模型轮询与串行播放并行。每句沿用当前 MOSS 音色、流式脉冲编码音频（PCM）、语速和音量；浏览器后端使用逐句播报任务。停止、打断、清理和新话语取消当前生成、当前音频及余句。完整队列结束后恢复监听，播报失败明确显示，不隐式切换输出后端。

## 原生契约与验证

核对当前 Stage0 使用的 DSH 0.2.1-alpha.1 创建、作用域工具、提示词、流事件及沙箱日志接口。原生工具 JSON Schema（JSON 数据约束）仅支持有限语法，因此可空更新时间采用 oneOf（两种类型择一），长度限制由 Host 校验，不使用原生拒绝的类型数组或 minLength／maxLength。

测试只加载源码；原生测试把已安装核心库装配到独立内存 Context，使用模拟模型，不装载启动器、Profile、持久化或服务器，也不接触真实项目会话。模型与音频行为测试使用模拟流和播放器；不能代替真实中文识别、声音品质和首音延迟验收。
