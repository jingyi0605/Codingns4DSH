# 名称同一行头像微调与成熟裁剪组件接入

日期：2026-10-07

## 实现结果

同行的头像展示尺寸为 44×44，与名称输入框的 44px 高度匹配，保持顶边对齐。

在助理配置「基本」页同一行显示名称与头像设置：名称在左，头像及「微调头像」按钮在右。说明及裁剪面板在下方跨两列展开，窄屏保持左右顺序。点击「微调头像」展开圆形裁剪区域，支持拖动、触控、方向键和缩放滑杆，实时预览小头像。点击「保存头像」确认后，同步更新助理正式/流式消息与全局按钮；取消保持原头像，首次创建的同一表单也提供入口。只读连接禁用修改。

采用 [react-easy-crop](https://github.com/ValentinH/react-easy-crop)（成熟 React 图像裁剪组件）固定版本 5.5.6。拖动及缩放由组件处理，CodingNS 仅实现透明 PNG 像素输出和统一头像服务持久化。组件自动注入其自身样式，裁剪区域使用固定高度及自适应宽度；禁用滚轮缩放，保留设置页滚动行为。

## 来源与适配器

渲染器新增可选 `createPortraitSource(model, signal)`，只在打开编辑器时请求完整静态来源。内置角色和图片返回最长边 512px 的静态帧，动作图集严格截取待机首帧；Live2D 优先使用同资源、同构图的透明预览，缺少时按既有生命周期临时初始化、捕获并销毁实例。原 `createPortrait` 自动头像接口仍保持兼容，没有完整来源接口的扩展可微调已有头像。

确认结果统一输出 128×128 透明 PNG（便携式网络图像），不改写原形象素材。裁剪坐标验证拒绝非有限数值、负值、非方形及越界范围。图像读取、编码与存储沿用限时及取消信号，保存期间锁定交互；切换资源、只读或卸载取消编辑并释放临时 URL（资源地址）。

## 持久化与共享

自动头像仍使用原独立缓存的八项、30 天期限。用户微调头像属于设置，保存到新的 IndexedDB（浏览器本地数据库）`codingns-assistant-avatar-portrait-overrides`，最大 21 项与形象容量对齐，不设置到期时间；图片与原始帧百分比裁剪位置一同保存。再次打开时恢复上次构图，避免在已裁好的缩略图上反复裁切。

手动记录按角色、资源与适配器版本隔离，切换形象保留各自头像，删除形象清理对应手动设置及自动缓存。消息和按钮继续订阅同一个服务、使用同一资源地址。写入成功后才发布新图片；存储失败、取消或非法结果保留原头像。读取手动记录之前禁止早到的自动帧抢占，后续动画帧也不能覆盖已确认的头像。

这些记录仅保存在当前浏览器，不跨设备同步。用户清理网站数据、浏览器存储被回收或资源版本变化时，可能需要重新调整；界面直接说明本地保存范围。
