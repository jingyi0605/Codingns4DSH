# 插件设置开关右对齐与样式统一记录

## 问题与处理

原有设置行只按文案自然宽度排列复选框，导致开关位置随说明长度变化；订阅用量的设置图标位于开关右侧。各模块还混用了原生复选框和自制标题栏开关。

新增 `src/client/settings-controls.ts`，统一启用控件与设置行：

- `SettingsSwitch` 使用真实复选框承载 `switch`（启用开关）语义，圆角、滑块和颜色沿用 DSH 主题令牌。模块轨道为 36×20 像素，子设置为 28×16 像素，二者点击区域高度均保留 28 像素。
- `SettingsToggleRow` 将文案与右侧操作分开。文案允许换行，操作区不收缩，设置图标先于开关排列。
- 文案通过 `htmlFor` 关联开关；图标按钮独立于标签，打开设置不会误切换选项。
- 模块标题与正文统一左右留白，使标题栏开关与子选项落在同一条垂线上。
- 样式仅匹配插件自己的控件类名，覆盖明暗主题、键盘焦点、按钮交互态、禁用态和减少动效偏好。多个面板共享一份样式，最后一个控件卸载后释放。

接入范围包括模块标题栏、工作区会话增强、文件管理、移动端及 PWA（渐进式网页应用）、局域网自动启动、登录保护、终端光标闪烁、外部 Agent 与子代理托管、助理形象和会话提醒设置。已有配置字段、保存路径、禁用条件及事件处理保持兼容。

## 模块与子设置的视觉层级调整

用户反馈两级开关完全一致，密集排列的深色轨道造成视觉干扰。本轮让模块标题栏显式传入 `variant: 'module'`，保留主开关尺寸与主色；其他调用默认使用更小的子设置规格。

子设置保留 28×16 像素的小尺寸；按用户后续要求，启用色使用 DSH 主题蓝色，滑块为白色。设置行标题字重降为 500，分隔线改为 0.5 像素。右侧对齐、设置图标位置、保存回调和禁用语义保持兼容。

工作区会话、第三方形象和助理提醒配置三组回归共 25 项通过。六种明暗主题与屏宽组合中，模块实测 36×20、子设置 28×16，右边缘差值仍为 0 像素；标签、键盘、焦点环和图标独立点击均通过验证。混合工作区的全量类型检查被 `global-voice-assistant.ts` 的 `notification` 属性类型错误阻挡。
