# 实时通话收起与悬浮字幕实现记录

日期：2026-10-08。

## 用户可见行为

- 通话页右上角增加「收起通话」，连接中也可以收起。
- 已开启悬浮助手时融合到当前助手，未开启时显示轻量通话球。
- 两种入口均可拖动，显示持续通话时长、实际发声提示和字幕气泡。
- 字幕保留当前轮用户转写和助理完整累计回复；默认跟随新文字，向上滚动时保留位置，下一轮恢复跟随。
- 点击悬浮入口或字幕气泡顶部恢复同一次通话，计时、静音和播放设备状态保留。
- 通话结束清除通话角标；启动失败和致命错误恢复窗口并显示原因。普通悬浮助手仍遵守原开关。

## 实现

GlobalVoiceOverlay 分开保存窗口打开与通话收起状态。收起保持 AssistantWorkbench 挂载，只隐藏窗口，不调用适配器 start／stop，不中断采集、播放、增量订阅或租约心跳。计时起点在请求通话时固定并传给窗口与悬浮组件；Host 归档继续采用实际租约时间。

隐藏窗口暂停计时刷新、关闭 Escape 监听并卸载动画形象，减少后台渲染。隐藏期间不滚动零尺寸字幕区域，恢复后重新执行跟随逻辑。

FloatingAssistantAvatar 和 FloatingVoiceCall 共用拖动容器。通话球独立记忆位置，原助手沿用已有存储键。拖动和点击恢复互斥；Enter、空格也可恢复。字幕气泡在拖动区域之外，可以独立滚动和选中文字。

计时角标每秒更新，发声动画取实际 speaking 状态并排除关闭扬声器。思考、收音、麦克风静音、扬声器关闭、连接中和异常分别提示；LLM（大语言模型）文字先到时不会提前显示发声动画。

字幕替换累计快照，保留全部句子并通过 React 转义文本。气泡在悬浮组件上下选择较宽裕的一侧，左右保留视口边距；拖动和窗口尺寸变化后重新布局，极矮横屏允许部分覆盖形象以保留字幕及恢复入口。
