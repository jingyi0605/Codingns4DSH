# 助理对话状态与底部输入栏优化记录

日期：2026-10-07

## 调整结果

- 名称右侧增加小字状态标签：思考中、认知更新、空闲、工作中。活动状态优先于项目索引，不再在形象下方重复展示项目认知状态。
- 标题、消息区和底部输入区分开布局；消息区独立滚动，输入栏与维护图标留在窗口底部。输入栏使用宿主主题、圆角背景、麦克风和圆形发送／停止图标。
- 删除独立「开始实时对话」按钮行、Sherpa 不可用说明段落和「对话维护」折叠区。麦克风未就绪时禁用，并用提示引导至声音管理。
- 压缩、清理仅作为输入栏下方的两个图标保留，可通过可访问名称和提示识别；压缩仍要求超过三轮消息，清理先弹出一次确认。
- 重置移至「配置 → 更多设置」，必须通过两次模态确认。第一次仅打开第二步，第二次确认才调用既有重置接口；任一步取消均不执行。

## 实现边界

`assistant-workbench-controls.ts` 集中放置状态标签、输入栏、维护图标与确认框，原 `AssistantComposer` 导出继续兼容。状态直接由现有快照派生，不增加持久字段或额外轮询。

确认阶段采用 `clear`、`reset-first`、`reset-final`。两次确认分别挂载原生 `dialog`，取消按钮获取默认焦点，Escape 不关闭整个工作台；执行期间禁止重复确认，失败保留当前阶段。最终操作继续复用原生命周期逻辑：停止生成与语音，重置配置和派生数据，保留原始项目会话及下载素材。

初始化仍只提供四项身份字段，没有对话输入栏、维护图标或重置入口。创建后的四个配置标签、形象预览、自定义头像、声音向导及资源安装流程保留。
