# 20261007-统一形象头像生成与入口接入记录

## 结果与数据关系

当前选择是头像的唯一来源，用户无需再上传、选择或保存一张头像。助理对话的正式消息和流式回复、侧栏 `data-codingns-global-voice-button` 使用同一头像服务。按钮保留原来的大小、焦点、无障碍说明及打开工作台的动作；头像更新不启动语音或重建原生会话行。

头像是现有形象的派生资源，没有新增形象清单字段、Host 设置或第三方美术素材。对话的全身展示仍使用原插槽及独立开关。已有工作区改动保留，本轮未构建、发版、推送或操作 Stage0、dsh-web、Desktop。

## 自动生成与扩展兼容

渲染适配器新增可选 `portraitVersion` 和 `createPortrait(model, signal)`，生成服务不按角色 ID 识别人物。基本形象裁随包透明图片；图片形象取待机差分；v1/v2 动作图集严格只取左上 192×208 待机帧。先在最长边不超过 512px 的画布分析透明轮廓，再裁上部角色，输出 128×128 PNG（便携式网络图像）。保留透明边缘，避免裁切坐标越界压缩头像。

Live2D 优先裁已有透明全身预览，没有预览时生成一次临时形象实例，捕获后销毁并移除画布。插槽提供现成帧时可取消临时生成；两种展示确实使用同一模型与构图才复用。多条消息和按钮共享一次头像任务，不为每条消息初始化引擎。只有预览接口的旧扩展继续兼容；完全没有预览或头像能力的扩展使用默认头像，原形象展示不受影响。

这是通用透明轮廓裁切，不调用外部人物识别。特殊构图可由适配器提供自己的生成函数。外链图片不允许跨域读取像素时回退默认头像，建议通过已有安装器使用本地同源素材。

## 缓存与生命周期

每个 Client 共用一个服务。资源地址、待机差分、双展示构图、头像与预览适配器版本构成缓存键；名称、语音状态和 UI（用户界面）展示尺寸不触发重新生成。切换后立即订阅新键，旧任务取消且迟到结果不发布、不落盘。

头像单独保存在 IndexedDB（浏览器本地数据库）`codingns-assistant-avatar-portraits`，不挤占全身预览数据库。沿用最多八项、30 天、单项 512KiB 的限制；内置头像输出 128px，扩展最多 256px。刷新读取已生成头像，无需为头像重新初始化 Live2D；实际全身动画仍按原流程加载。内存保留八个无订阅头像，淘汰时释放临时 URL（资源地址），删除角色同时取消任务和清理头像缓存。

存储禁用、跨域限制、图片解码/编码失败和引擎缺失不阻断对话。所有快照读取都不启动任务，服务端渲染仍可使用旧组件调用方式。
