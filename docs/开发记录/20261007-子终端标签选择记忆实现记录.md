# 子终端标签选择记忆实现记录

日期：2026-10-07。

后续修正：本记录中的“会话卡片独立选择”作用域已由用户明确纠正为工作区共享。当前实现见 `docs/开发记录/20261007-终端工作区共享选择与卡片状态修复记录.md`，以下保留上一轮实现与验证经过。

## 问题与判断

聚合终端页把列表和选中标签保存在 React 组件状态中。组件卸载后选中记录消失，重新打开时回退到第一个终端；组件被复用时，还可能短暂沿用上一张卡片的列表。

终端库存由工作区共享，选中标签则是每张会话卡片的浏览偏好。选择记录需要由终端服务保存，并与组件生命周期分离。

## 实现

- `src/client/terminal/model.ts`：增加按 `sessionId` 保存的选中终端记录和选择变更订阅。
- 持久记录使用浏览器存储键 `dsh.codingns.terminal.selection.v1.` 加上 JSON 编码的会话 ID，只保存最近选中的终端 ID。
- `src/client/terminal/ui.ts`：直接读取当前会话的服务库存和选择，点击子标签时同步保存，不再保留组件内的列表副本与选择副本。
- 创建成功后选中新终端；库存刷新和重命名保留仍然有效的选择。
- 同工作区库存更新时校验各卡片的选择。选中终端被关闭后回退到首项，库存为空时移除记录。
- 首次库存尚未加载时保留已有选择记录，不把组件初始空状态当作终端已关闭。浏览器存储读写失败时使用内存记录。

Host（宿主）的终端身份、进程和连接生命周期保持原逻辑；卡片切换和选择恢复不调用创建或关闭接口。
