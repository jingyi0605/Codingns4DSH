# DSH 0.2.2-rc.3 兼容性调查

## 结论

Codingns4DSH `0.2.2-rc.5` 将 DSH 已验证版本更新为 `0.2.2-rc.3`，最低兼容范围继续保持 `>=0.2.1-alpha.2`。当前插件使用的 DSH API 与 `0.2.2-rc.3` 兼容，不需要新增版本专用业务适配器。

## 调查证据

- DSH `v0.2.2-rc.3` 发布说明：新增实验性 DeepSeek 会话导入插件，并修复 Windows Desktop 应用内更新失败后无法重新打开的问题。
- 直接引用的 DSH 包均可从 npm 获取 `0.2.2-rc.3` 版本，包含 `dsh-app-boot`、Session、SubAgent、Agent Team、Web、Context Menu、Workspace 和 Sidebar 相关包。
- 对 `0.2.2-rc.2` 与 `0.2.2-rc.3` 的已引用包进行了声明文件和运行时代码比较。Sidebar bundle 的释放回调保持不变，仍需要现有 `SidebarSessionView` 兼容补丁；Workspace UI 的变化是新增导出和工厂能力，插件没有直接导入该包，因此不影响现有适配器。

## 兼容性变更

- 将 `version.json.dshTestedVersion`、源码中的 DSH 测试版本和 Profile 测试版本更新为 `0.2.2-rc.3`。
- 将所有直接锁定的 `@deepseek-ai/dsh-*` 依赖更新为 `0.2.2-rc.3`。
- 保留 `>=0.2.1-alpha.2` 的安装和激活下界；新版本宿主继续使用结构探测和能力矩阵，未验证版本仅显示提示。
- 保留 Sidebar Session 兼容层对 `0.2.2-rc.2` 的限定补丁，不将其扩展到 `rc.3`，因为 `rc.3` bundle 的相关回调仍与已核对版本相同，且现有补丁集合仍按实际版本精确控制。

## 验证范围

- 运行版本号门禁，确认插件版本 `0.2.2-rc.5` 符合仓库既有 `rc.N` 约定。
- 更新 lockfile 后运行 `pnpm run version:check`、`pnpm run typecheck`、`pnpm run capability:check` 和受影响的测试。

参考：[DSH v0.2.2-rc.3 Release](https://github.com/deepseek-ai/deepseek-harness/releases/tag/dsh-v0.2.2-rc.3)
